# 한글 생활 경제

1.2 버전은 **NPC 우클릭 상점**, 직업, 일일 임무, 매입 한도를 제공합니다. [10인 생활 서버 설치·운영 안내](../life-server/README.md)를 참고하세요. `/상인 생성 농부 농산물`로 사람형 상인을 배치하거나 마지막에 `주민`을 붙일 수 있습니다. 대상 API는 Paper 26.3입니다.

EssentialsX의 잔액을 Vault로 공유하는 서버 상점과 일일 보상 플러그인입니다. 별도 지갑을 만들지 않습니다. Vault와 실제 경제 제공자(EssentialsX 등)가 있어야 거래·보상을 사용할 수 있습니다.

| 명령어 | 기능 |
| --- | --- |
| `/상점` | NPC 상점 이용 방법 안내(원격 열기 기본 꺼짐) |
| `/상인 생성 이름 품목 [사람|주민]` | 운영자용 NPC 배치 |
| `/상인 삭제`, `/상인 목록` | 주변 NPC 관리 |
| `/일일보상` | 설정된 날짜 기준 하루 한 번 보상 |
| `/경제안내` | 한글 생활 경제 명령어 안내 |
| `/경제설정 새로고침` | 운영자용 설정 다시 읽기 |

기본 시간대는 한국, 보상은 200원입니다. 상점은 판매 모드로 열리고 아래 버튼으로 구매 모드를 선택합니다. 좌클릭 1개, 쉬프트 클릭 16개, 우클릭 64개를 거래합니다. 이름·마법·설명 등 추가 정보가 없는 기본 아이템만 취급하며 장비·보조 손을 제외한 보관 슬롯만 사용합니다. 창작·관전자 모드에서는 거래할 수 없습니다.

`plugins/KoreanEconomy/config.yml`에서 매입·판매 가격과 보상을 설정합니다. `구매가`는 플레이어가 지불하는 가격, `판매가`는 플레이어가 받는 가격입니다. 각 가격은 1~100만 사이 정수이며 판매가가 구매가보다 높으면 설정을 거부합니다. 재설정 실패 시 실행 중이던 설정을 유지합니다.

일일 보상은 UUID별 날짜와 처리 상태를 UTF-8 파일로 기록합니다. 외부 경제 플러그인 호출 전에 `처리중`을 저장하고 지급 성공 후 `완료`로 바꿉니다. 처리 도중 중단되면 중복 지급을 막기 위해 운영자 확인을 요구합니다. 해당 기록을 지우면 보상을 다시 받을 수 있으므로 운영자는 로그와 실제 잔액을 먼저 확인해야 합니다. 거래는 동기 서버 스레드에서 처리합니다. 외부 경제 저장소와 마인크래프트 플레이어 저장 파일 사이의 장애 원자성까지 보장하는 데이터베이스 트랜잭션은 아닙니다.

## 빌드와 검사

```powershell
./life-server/Build-LifePack.ps1 -PaperServer 'C:\Paper26.3서버' -JavaHome 'C:\Program Files\Java\jdk-25'
./life-server/Package-LifePack.ps1
```

설치된 서버의 Paper 26.3 build 238, Vault, GriefPrevention 실제 API로 컴파일합니다. `korean-economy/build.py --paper-server ... --java-home ...`도 동일한 빌드를 호출합니다. 실제 서버와 별도 테스트의 검증 범위는 [검증 결과](../life-server/검증.md)에 있습니다.
