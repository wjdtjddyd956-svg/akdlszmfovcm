# Paper 26.3 경제 팩 수정

이전 안내에서 JAR만 복사하도록 안내해 시작 잔액·통화·언어 설정이 빠졌습니다. 이 수정 플러그인은 설정 파일을 직접 찾아 **한 번만** 적용합니다. EssentialsX 본체의 미지원 오류는 별도로 공식 개발 빌드 교체가 필요합니다.

## 1. EssentialsX 본체·스폰 교체

- 공식 안정판 2.22.0에는 26.3 지원이 없습니다. 실제 서버에서 미지원 메시지가 확인되었습니다.
- 2026-11-10 확인한 [공식 개발 브랜치](https://github.com/EssentialsX/Essentials/tree/2.x)는 README와 `VersionUtil.java`의 지원 목록에 26.3을 포함합니다.
- [공식 다운로드](https://essentialsx.net/downloads.html)의 **개발 빌드**에서 EssentialsX와 EssentialsXSpawn을 같은 빌드로 받으세요. 공식 사이트와 빌드 서버는 이 클라우드에서 HTTP 403으로 차단되어 여기서 JAR를 확보하지 못했습니다. 수정 ZIP에는 이 JAR 2개가 없습니다.
- Windows에서는 수정 ZIP 폴더에서 아래 스크립트로 받을 수도 있습니다. 공식 Jenkins의 같은 성공 빌드에서 두 파일을 고르고, 플러그인 이름·버전 일치와 본체의 26.3 지원 식별자를 검사합니다. 스크립트가 실패하면 기존 JAR를 교체하지 말고 공식 사이트에서 직접 받으세요. Windows 실제 실행·Jenkins 호출은 이 환경에서 미검증입니다.

```powershell
powershell -NoProfile -File .\EssentialsX-개발빌드받기.ps1
```

스크립트는 받은 파일을 별도 다운로드 폴더에 저장하며 서버를 직접 수정하지 않습니다. SHA-256은 다운로드 기록용으로 계산하고, 원격의 서명된 체크섬과 비교하는 방식은 아닙니다. 확인한 공식 소스의 26.3 식별자를 검사해 오래된 빌드 선택을 막지만 게임 안의 실제 동작 검사를 대신하지 않습니다.

서버를 `stop`으로 종료하고 기존 `EssentialsX-2.22.0.jar`·`EssentialsXSpawn-2.22.0.jar`만 백업한 뒤 새 두 JAR를 넣으세요. 같은 플러그인은 한 버전만 둡니다. **`plugins/Essentials`와 다른 데이터 폴더는 지우지 않습니다.** 기존 월드를 낮은 버전의 서버로 열어 해결하지 마세요.

## 2. 설정 수정 JAR 추가

서버가 꺼진 상태에서 수정 ZIP의 `plugins/KoreanPackSetup-1.0.0.jar`를 서버의 `plugins`에 넣고 시작하세요. 기존 한글 메뉴·명령어·경제 플러그인은 그대로 둡니다.

이 플러그인은 시작 단계에 Essentials·QuickShop보다 먼저 설정을 읽고 아래 항목만 변경합니다.

- 신규 유저 시작 잔액: **1000원**
- Essentials 언어: 한국어, 통화: **원** 접미사
- QuickShop 언어: 한국어, 내장 한국어 덮어쓰기 적용
- QuickShop 아이템 표시: `shop.display-items: true`, `shop.display-type: 3`

QuickShop의 3번 방식은 실제 표시 엔티티를 사용하므로 ProtocolLib·PacketEvents가 필요하지 않습니다. 공식 6.3.0.4 소스의 `DisplayType.DISPLAY_ENTITY(3)`와 해당 구현·환경 검사를 확인했습니다. 실제 상자 위 표시 여부는 서버에서 확인해야 합니다.

원본 설정·번역 파일은 `plugins/KoreanPackSetup/백업-날짜-식별자`에 저장합니다. 설정을 모두 읽고 파싱한 뒤 백업·적용하며 중간 파일 쓰기 실패 시 변경한 파일을 복구합니다. 실패 중 디스크 자체가 고장 나는 경우에는 로그와 백업으로 수동 확인해야 합니다. YAML 파서가 다시 저장하므로 주석·들여쓰기 형식은 달라질 수 있지만 다른 설정 값은 보존합니다.

적용 뒤 완료 기록을 남겨 다음 시작 때 운영자가 수정한 가격·언어를 다시 덮어쓰지 않습니다. `/경제팩설정`은 상태를 보여주며 운영자만 사용할 수 있습니다. `/경제팩설정 다시적용`은 새 백업을 만들고 재적용하며, **서버를 재시작해야** 각 플러그인의 메모리 설정에 반영됩니다.

## 기존에 접속한 계정의 잔액

시작 잔액 1000원은 **앞으로 처음 접속하는 유저만** 해당합니다. 이미 생성된 계정이 0원이면 이번 수정으로 자동 지급하지 않습니다. 기존 잔액·집·스폰·상점 데이터 파일은 바꾸지 않습니다. 운영자가 필요한 계정에만 한 번 지급하세요.

```text
/돈관리 지급 닉네임 1000
```

## 게임 안에서 확인

Vault 연동 성공만으로 기능 검증이 끝난 것은 아닙니다. 개발 빌드 교체와 설정 적용 후 아래를 확인하세요.

1. `/플러그인목록`으로 Essentials·EssentialsSpawn·QuickShop-Hikari·KoreanPackSetup 활성화 확인.
2. `/돈`에 원화 표시, 새 테스트 계정 최초 접속 잔액 1000원 확인.
3. 두 계정으로 `/송금 닉네임 1`을 실행해 송금자 -1원·수신자 +1원 확인.
4. `/집저장` 후 이동해서 `/집`으로 복귀 확인.
5. 운영자가 `/스폰설정` 후 `/스폰`으로 이동 확인.
6. 유저 상자 상점에서 한국어 안내와 표시 아이템 확인.

현재 제공물은 실제 SnakeYAML 파싱·실제 파일 백업/복구·잔액 데이터 보존·일회 적용 검사까지 수행했습니다. **Paper 26.3 실서버·Windows 다운로드 스크립트 실행은 미검증이고, 본체 개발 JAR 다운로드도 차단으로 미완료입니다.** 미지원 메시지를 지우거나 버전 숫자만 바꾼 JAR를 만들지는 않았습니다.

## 재빌드

컴파일용 SnakeYAML 2.2 JAR는 공식 Maven에서 `survival-pack/vendor/setup/snakeyaml-2.2.jar`로 받습니다. SnakeYAML은 Paper가 제공하며 결과 JAR에는 포함하지 않습니다. 기존 묶음의 공식 기본 설정·한국어 리소스를 사용합니다.

```bash
python3 korean-pack-setup/build.py
python3 survival-pack/build_fix.py
```

Bukkit 클래스는 기존 오프라인 최소 시그니처 fixture로 컴파일하고 테스트 fixture는 JAR에 포함하지 않습니다. YAML 파싱·파일 작업은 실제 라이브러리와 파일 시스템으로 검사합니다.
