# 빌드·검증과 배포 출처

배포 대상은 Paper 26.3, Java 25입니다. 생산 JAR는 테스트용 Bukkit fixture로 만들지 않습니다. 사용자 서버와 동일한 Paper 커밋 `df120fd8b5211f61146a59f69497a5a62064b917`의 수정하지 않은 API 소스를 Java 25로 빌드해 컴파일했습니다. 이는 공식 게시 API 바이너리나 서버 배포판이 아닙니다.

## 준비와 재현

다음 파일은 저장소 외부의 `/workspace/toolchains`에 준비합니다. 다른 위치는 `TYCOON_TOOLCHAINS`, `TYCOON_JDK`, `PAPER_API_JAR`, `PAPER_API_DEPS` 환경변수로 생산 빌드에 지정할 수 있습니다. 테스트 도구 기본 경로는 `/workspace/toolchains`입니다.

- Oracle OpenJDK 25: `https://download.oracle.com/java/25/latest/jdk-25_linux-x64_bin.tar.gz`, 현재 `jdk-25.0.5.0.3/`.
- Gradle 9.8.0: 공식 Gradle 배포 ZIP, `gradle-9.8.0/`.
- Paper 소스: `https://github.com/PaperMC/Paper/archive/df120fd8b5211f61146a59f69497a5a62064b917.zip`, `paper-source/Paper-df120fd/`.
- Brigadier 소스: `https://github.com/Mojang/brigadier/archive/9ba4f13c0fe82b07c08c2dc2d8043f075ffd0d98.zip`, `brigadier-source/brigadier-master/`.
- 기존 `survival-pack/fetch_vendor.py`로 Vault·QuickShop·기존 설정 템플릿용 Essentials 2.22.0 및 해당 소스를 준비합니다. 미지원 Essentials JAR는 새 배포에 넣지 않고 한국어 설정·라이선스만 읽습니다.
- `survival-pack/vendor/tycoon/`에 Maven Central의 `org.xerial:sqlite-jdbc:3.51.0.0`, `org.slf4j:slf4j-api:2.0.17`, `org.slf4j:slf4j-simple:2.0.17`을 각각 `sqlite-jdbc.jar`, `slf4j-api.jar`, `slf4j-simple.jar`로 준비합니다.
- 설정 테스트용 `survival-pack/vendor/setup/snakeyaml-2.2.jar`와 기존 한글 설정 ZIP은 이전 배포물에서 사용합니다. 리소스팩 생성에는 Python Pillow가 필요합니다.

```bash
python3 tools/build_exact_paper_api.py
python3 korean-economy/test_domain.py
python3 tools/test_tycoon_integration.py
python3 korean-pack-setup/build.py
bash korean-commands/build.sh
python3 tools/build_tycoon.py
python3 tools/test_installer.py
python3 tools/build_tycoon_resourcepack.py
python3 tools/package_tycoon.py
```

API 전용 빌드는 Mojang Brigadier를 위 커밋 소스에서 빌드하고 의존성을 Maven Central에서 받습니다. API의 Paper 전용 구형 Bungee 컴파일 의존성 대신 Central의 `net.md-5:bungeecord-chat:1.21-R0.4`를 사용했습니다. 자체 플러그인은 Bungee API를 호출하지 않습니다. 이 대체를 포함한 출처는 `build-provenance.json`에 남깁니다.

## 검증 구분

- 도메인과 거래 장애 주입: 실제 SQLite JDBC, 파일 DB, 재시작·한도·중복·환불 실패·복구 대기 검사.
- Bukkit 통합: 실제 `org.mockbukkit.mockbukkit:mockbukkit-v26.3:4.120.0`과 실제 Paper API. Vault 경제 제공자는 테스트 대역으로, 실제 Essentials와 통합 실행한 것은 아닙니다. MockBukkit이 구현하지 않은 `Player.saveData()`만 테스트 Player에서 저장 호출 횟수로 대체합니다. 실제 NBT 저장·접속·Paper 엔진은 검증하지 못했습니다.
- 메뉴 연동: 쉬프트+F 메뉴·한글 명령 경로, 운영자 메뉴 클릭으로 권한을 올리지 않는지 확인합니다.
- 설정 변경: 실제 SnakeYAML과 파일 시스템에서 29개 검사. Bukkit 생명주기는 기존 fixture이며 생산 JAR 컴파일과 별개입니다.
- 설치 도구: 실제 Linux 파일 시스템·SHA-256·손상 ZIP·경로 탈출·파일 잠금·전체 복원·재설치 검사. 테스트 플러그인 메타데이터 fixture는 런타임 플러그인 성공으로 계산하지 않습니다.
- 생산 JAR 패키징: ZIP 무결성·플러그인 메타데이터·필수 설정 리소스·API 클래스 미포함·내장 SQLite 구동 검사.

클라우드 정책이 공식 Paper·Mojang 서버·Essentials CI 도메인을 차단하고 있어 실제 Paper 서버 부팅·Minecraft 클라이언트 접속은 수행하지 못했습니다. 16개 공식 도메인을 허용하는 환경 초안을 저장했지만 게시되지 않은 설정을 적용됐다고 간주하지 않습니다. 차단을 다른 주소로 우회하지 않습니다. 공유 Windows 서버 연결도 없습니다.

## 타사 배포

Vault·QuickShop은 공식 JAR를 수정하지 않고 포함하며 원본 소스 ZIP·다운로드 URL·SHA-256을 함께 제공합니다. Essentials의 본체·Spawn은 설치 시 공식 CI에서 직접 받습니다. 개발 빌드의 한국어 번역은 추가된 문구까지 모두 번역됐다고 보장하지 않습니다. 일반 기능과 자체 메뉴·명령어는 한국어로 제공합니다.

SQLite JDBC는 생산 KoreanEconomy JAR에 포함하며 서버가 제공하는 SLF4J를 사용합니다. 테스트용 SLF4J Simple, Paper API, Vault API 및 MockBukkit은 자체 플러그인 JAR에 넣지 않습니다. SQLite JDBC의 원래 라이선스·네이티브 라이브러리 리소스를 보존합니다.
