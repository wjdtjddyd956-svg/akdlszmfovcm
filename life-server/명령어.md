# 한글 명령어

| 플레이어 명령 | 동작 |
| --- | --- |
| 쉬프트+F 또는 `/메뉴` | 생활 메뉴 |
| `/돈`, `/송금 닉네임 100` | 잔액과 송금 |
| `/집저장`, `/집`, `/스폰` | 집 저장·이동, 스폰 이동 |
| `/일일보상`, `/경제안내` | 일일 접속 보상과 한글 도움말 |
| 상점 NPC 우클릭 | NPC 구매·판매, 남은 서버 매입 한도 확인 |
| `/거래소 생성 100` | 아이템을 들고 상자를 바라본 상태에서 QuickShop 생성 |
| `/직업` | 선택·변경·레벨·적립 보상 |
| `/임무` | 임무 상태 확인. 안내 NPC 우클릭으로 수락·완료 |
| `/땅보호`, `/땅보호 확인`, `/땅보호 목록` | 땅 도움말, 현재 보호 범위, 내 땅 목록 |
| `/땅보호 초대 닉네임` | 내 땅의 건축·상자 권한 부여 |
| `/땅보호 상자초대 닉네임` | 내 땅의 상자 이용 권한 부여 |
| `/땅보호 회수 닉네임`, `/땅보호 해제 확인` | 해당 위치 내 권한 회수·보호 해제 |

| 운영자 명령 | 동작 |
| --- | --- |
| `/상인 생성 잡화상인 전체` | 현재 위치에 잡화상인 생성 |
| `/상인 생성 임무안내 일일임무` | 현재 위치에 일일 임무 NPC 생성 |
| `/상인 생성 농부 농산물 주민` | 농산물만 거래하는 주민 생성 |
| `/상인 목록`, `/상인 삭제` | 주변 NPC 확인·가장 가까운 상인 제거 |
| `/기록조회 닉네임 1h 16 상자` | 현재 월드 반경 16, 최근 1시간의 상자 기록 |
| `/기록조회 페이지 2` | 다음 결과 페이지 |
| `/복구 미리보기 닉네임 1h 16 블록` | 현재 위치 근처에서 블록 복구 미리보기 |
| `/복구 적용`, `/복구 취소`, `/복구 되돌리기` | 미리보기 적용·취소, 최근 적용 되돌리기 |
| `/백업 상태`, `/백업 지금` | 백업 상태와 정상 종료 기반 즉시 백업 |
| `/경제설정 새로고침` | 보상·가격·한도 다시 읽기 |
| `/경제거래 UUID 확인\|완료\|취소` | 중단된 거래 기록을 운영자 확인 후 정리 |
| `/스폰설정` | 운영자 위치를 서버 스폰으로 지정 |

조회·복구 범위는 1~128블록이며 시간 단위는 `m`(분), `h`(시간), `d`(일)입니다. 유형은 `전체`, `블록`, `상자`입니다.
