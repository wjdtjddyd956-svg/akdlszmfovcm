# 쉬프트+F 한글 마을 수첩 2.0

Paper 26.3에서 쉬프트+F 또는 `/메뉴`로 잔액·NPC 상점·직업·요리·강화·임무·땅 보호·집·스폰 화면을 엽니다. 일반 F키는 보조 손 바꾸기를 유지합니다. 모든 연결 명령을 플레이어 권한으로 실행하며 OP를 부여하지 않습니다. 창 안의 단축키 이동·아이템 끌어오기를 차단합니다.

[현재 설치 안내](../../../사용안내/생활타이쿤/시작안내.md) · [실제 API 검증](../../../사용안내/생활타이쿤/개발검증.md)

`python3 개발자료/플러그인/마을수첩/build.py`는 실제 Paper API로 생산 JAR를 빌드합니다. 쉬프트+F에서 직업 화면으로 가는 경로는 실제 MockBukkit 통합 검사로 확인합니다. 기존 fixture 기반 MenuEventTest는 이전 버전 이력이며 최신 검증 결과에 합산하지 않습니다.
