# 명령어와 메뉴

| 대상 | 명령/동작 | 실제 동작 |
| --- | --- | --- |
| 이용자 | 쉬프트+F → 마을 안내·서버 정보 | 실제 잔액·직업·농부 레벨·적립금·도감·업적·접속자 표시 |
| 이용자 | /마을정보 | 같은 안내 화면 |
| 이용자 | /정보표시 | TAB 생활 정보판 전환. 원래 tab.scoreboard.toggle 권한 검사 |
| 이용자 | /야생 | 검증 대기 안내. 이동·비용 차감 없음 |
| 기존 명령 | /메뉴 /돈 /송금 /집 /스폰 /상인 | 기존 명령·권한·비용·대기시간 유지. /상인은 기존 운영자 명령 |
| 기존 기능 | /직업 /요리 /강화 /임무 /농사 /도감 /업적 /도감효과 /땅보호 | 기존 화면·기록 유지. 주요 기능은 메뉴/NPC 이용 |
| 운영자 | /권한관리 목록 | 원래 lp listgroups를 같은 이용자 권한으로 실행 |
| 운영자 | /권한관리 확인 닉네임 | 원래 lp user 닉네임 info |
| 운영자 | /권한관리 등급 닉네임 주민 또는 단골 또는 운영자 | 원래 lp user 닉네임 parent add 그룹. 기존 등급 보존. 원래 권한 필요 |
| 운영자 | /지형생성 상태·일시정지·계속·시작 | 각각 원래 chunky progress/pause/continue/start. 원래 개별 권한 검사 |
| 운영자 | /안내판관리 연결 | 소유 안내판 1개를 연결/갱신 |
| 운영자 | /안내판관리 목록 | 원래 dh list. 해당 버전은 게임 안 실행 필요 |
| 운영자 | /기록조회 /복구 /백업 | 기존 Prism 연결·Windows 백업 관리자 유지 |

권한관리 별칭은 원래 권한을 추가 지급하지 않습니다. 운영자 등급도 luckperms.user.parent.add를 받지 않으므로 다른 사람을 승급시킬 수 없습니다. 처음 등급 부여는 실제 서버 콘솔에서 다음처럼 합니다.

    lp user 실제닉네임 parent add resident
    lp user 실제닉네임 parent remove resident

parent set으로 기존 등급을 지우지 않습니다. OP 부여는 하지 않습니다. 금 삽으로 땅 지정, 기존 /땅보호 친구 초대·회수 화면을 우선 사용하세요. /trapped 등 외부 플러그인의 기존 고급 명령을 한글 명령으로 구현했다고 주장하지 않습니다.
