# 마인크래프트 26.1.2 Fabric 한글 모드

**현재 24종 중 공식 파일 7종을 확보했습니다. 바로 묶을 수 있는 기본 구성은 6종이며, Visuality는 Cloth Config 확인을 기다리고 있습니다.** 전체 24종이 준비됐다는 뜻은 아닙니다.

이 자료는 **PC의 Minecraft 26.1.2 Fabric 클라이언트**에서 사용합니다. Java 25 이상이 필요합니다. 검증에 사용한 로더 기준은 Fabric Loader 0.19.5입니다. 기존 Paper 26.3 서버·월드·플러그인은 변경하지 않습니다.

## 기본 구성 6종

| 한글 이름 | 공식 모드 | 확보 버전 |
| --- | --- | --- |
| 패브릭 API | Fabric API | 0.155.3+26.1.2 |
| 셜커 상자 미리보기 | ShulkerBoxTooltip | 5.4.3+26.1.1, 메타데이터가 26.1.2 허용 |
| 음식 회복량 표시 | AppleSkin | 3.0.10+mc26.1.2 |
| 엔티티 표시 최적화 | EntityCulling | 1.12.0, 26.1 계열 |
| 추가 동작 애니메이션 | Not Enough Animations | 1.12.7, 26.1 계열 |
| 모드 목록·설정 | Mod Menu | 18.0.2, 26.1 계열 |

JAR는 제작자의 공식 파일 그대로 사용합니다. 한글 파일명으로 정리해도 내부 모드 ID·버전·서명은 변경하지 않습니다. Minecraft 지원 범위와 필수 라이브러리는 JAR의 `fabric.mod.json` 및 포함된 내부 JAR까지 확인했습니다. **실제 게임 실행·셰이더·다른 모드와의 조합 검사는 아직 하지 않았습니다.**

## 방법 1: 새 프로필로 가져오기

`패브릭-26.1.2-한글기본6종.mrpack`을 Modrinth App이나 MRPACK을 지원하는 런처에서 가져옵니다. 새로운 26.1.2 Fabric 프로필에 공식 주소의 기본 모드 6개를 받고 한국어 팩과 언어 설정을 적용하도록 구성했습니다. 실제 런처 가져오기는 이 환경에서 실행하지 않았습니다.

## 방법 2: 한글 이름으로 공식 파일 받기

1. `패브릭-26.1.2-한글준비-1.0.0.zip` 전체를 새 폴더에 압축 해제합니다.
2. Windows에서 `모드받기.cmd`를 실행합니다.
3. **받은파일/mods**에 검증한 기본 JAR 6개를, **받은파일/resourcepacks**에 한국어 팩을 준비합니다. 기존 게임 폴더에는 쓰지 않습니다.
4. 새 26.1.2 Fabric 게임 프로필의 `mods`와 `resourcepacks`에 각각 넣습니다. 기존 1.20.1 모드는 별도로 보관하고 섞지 마세요.
5. Minecraft에서 **설정 → 언어 → 한국어**, **설정 → 리소스 팩 → 모드한글팩**을 선택합니다.

다운로드 도구는 공식 GitHub 주소·SHA-256·실제 Fabric 모드 ID·버전을 확인합니다. 같은 파일은 재사용하며 내용이 다른 기존 파일은 자동으로 덮어쓰지 않습니다. JAR를 수정하는 도구가 아닙니다.

## 한글화 범위

`모드한글팩-26.1.2-1.0.0.zip`은 리소스팩입니다. 모드 JAR의 기존 한국어 번역을 유지하면서 확인된 영어 메뉴·설명에서 부족한 문구를 보충합니다.

- 확보한 모드와 포함 라이브러리의 부족한 번역 234개
- Sodium 0.9.2 공식 태그의 설정·설명 105개. Sodium 본체는 현재 다운로드 대기
- Mod Menu에서 사용할 모드 한글 표시 이름 24개
- 합계 363개 언어 키

소듐·확인 대기 모드의 표시 이름을 준비한 것이 본체 확보나 전체 한글화 완료를 뜻하지 않습니다. 코드에 직접 들어 있는 모든 영어·운영 로그·다른 버전의 추가 문구까지 확인한 상태는 아닙니다. 기본 모드의 언어 키와 공식 Sodium 태그를 기준으로 검사했습니다.

## 확인 대기

현재 실행 환경은 Modrinth API와 파일 CDN 접속이 차단돼 있습니다. 이 환경에서 나머지를 확인하려면 저장해 둔 환경 설정 변경안을 검토·저장·게시하고, 적용된 환경에서 다시 확인해야 합니다. 초안 저장만으로 실행 환경의 차단이 풀리지는 않습니다.
