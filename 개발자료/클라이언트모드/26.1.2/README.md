# 26.1.2 Fabric 모드 확인·한글화

[사용자용 설치 자료](../../../설치파일/05_클라이언트모드/26.1.2/README.md) · [확보·확인 대기 범위](확인대기목록.md)

공식 GitHub에서 확인한 JAR와 공식 Sodium 태그를 기준으로 언어 키를 보충합니다. 원본 JAR는 수정하지 않습니다. 업로드한 1.20.1 파일을 버전 문자열만 고쳐서 새 버전으로 취급하지 않습니다.

- `호환검사.py`: JAR와 포함 JAR의 Fabric 메타데이터·의존 조건·Java 바이트코드 검사
- `보충번역.json`: 확보한 버전의 누락 한국어 문구
- `소듐번역.json`: 공식 mc26.1.2-0.9.2 태그의 문구
- `한글표시이름.json`: Mod Menu에서 사용할 표시 이름
- `언어검증-기준.json`: 실제 파일에서 추출한 언어 검증 기준과 출처
- `공식배포-고정목록.json`: 직접 확보한 파일·URL·버전·해시
- `모드받기.ps1`: 기본 모드 6개를 공식 주소에서 준비. 기존 게임 폴더 변경 없음

검증은 메타데이터·바이트코드·리소스팩·다운로드 도구 기준입니다. 실제 Minecraft 또는 Windows 게임 실행을 검증했다고 주장하지 않습니다. 외부 배포는 원본 다운로드 URL과 해시를 가진 MRPACK·도구로 제공하며 타사 모드 JAR는 GitHub에 다시 올리지 않습니다.

재현 명령: `python3 개발자료/클라이언트모드/26.1.2/묶음만들기.py` → `검사.py` → `다운로드검사.py` → `배포묶기.py`. 공개 고정 목록의 URL·해시로 입력을 다시 받을 수 있습니다. 다운로드 검사는 작업 폴더의 PowerShell 7.5.4를 사용하며 Windows 실행 검사와 구분합니다.
