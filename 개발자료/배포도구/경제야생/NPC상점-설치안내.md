# NPC 상점 교체 파일 1.1

Paper **26.3**용입니다. NPC를 우클릭하면 기존 Vault 잔액으로 거래하는 한글 구매·판매 창이 열립니다. 사람 모양은 Paper의 기본 `MANNEQUIN` 엔티티를 사용하며, 주민 모양도 선택할 수 있습니다. Citizens·FancyNpcs·ProtocolLib·PacketEvents는 필요하지 않습니다. 사람 모양은 기본 외형이며 플레이어 스킨을 지정하는 기능은 이번 버전에 넣지 않았습니다.

## 설치

1. 서버를 `stop`으로 종료하고 서버 폴더를 백업합니다.
2. 기존 `plugins/KoreanEconomy-1.0.0.jar`만 꺼내고, 이 ZIP의 `plugins/KoreanEconomy-1.1.0.jar`를 넣습니다. 같은 플러그인은 한 버전만 남깁니다.
3. **`plugins/KoreanEconomy` 설정·보상 기록 폴더는 지우지 마세요.** 기존 가격과 보상을 유지합니다. Vault와 실제 경제 제공자(EssentialsX 등)는 계속 필요합니다.
4. 서버를 시작하고 운영자 권한으로 NPC를 놓을 장소에 섭니다.

```text
/상인 생성 잡화상인 전체
```

현재 서 있는 위치에 사람 모양의 상인이 생깁니다. 한 걸음 물러나 우클릭하면 거래 창이 열립니다. 물건은 NPC의 종류에 맞게 표시합니다.

## NPC 배치 예시

아래 명령은 각각 NPC를 둘 장소로 이동한 뒤 입력하세요.

```text
/상인 생성 농부 농산물
/상인 생성 광물상 광물
/상인 생성 자재상 재료
```

| 품목 구분 | 거래 아이템 |
| --- | --- |
| 전체 | 기존 상점 품목 8종 |
| 농산물 | 밀·당근·감자 |
| 광물 | 석탄·철 주괴·다이아몬드 |
| 재료 | 조약돌·참나무 원목 |

주민 모양을 원하면 마지막에 `주민`을 붙입니다.

```text
/상인 생성 농부 농산물 주민
/상인 목록
/상인 삭제
```

`/상인 삭제`는 주변 4블록 안에서 가장 가까운 **이 플러그인의 상인 하나만** 지웁니다. 일반 주민은 건드리지 않습니다. `/상인 목록`은 주변 상인을 보여줍니다. `/상점엔피시`도 `/상인`의 별칭입니다. 생성·삭제·목록은 기본적으로 운영자만 사용할 수 있습니다.

## 거래와 메뉴

- 상인을 우클릭하면 판매 모드로 열립니다. 아래 버튼으로 구매/판매를 바꿉니다.
- 좌클릭 1개, 쉬프트 클릭 16개, 우클릭 64개입니다.
- 이름·설명·마법이 붙은 아이템과 장비·보조 손 슬롯은 기존 규칙대로 거래 대상에서 제외합니다.
- 상인으로부터 5블록 넘게 멀어지거나 상인이 없어지면 거래를 차단합니다.
- 쉬프트+F 메뉴의 서버 상점 버튼과 `/상점`은 이제 **상점 NPC를 우클릭하라는 안내**를 표시합니다.

예전처럼 `/상점`으로도 원격으로 열고 싶다면 설정에 아래 값을 추가할 수 있습니다. 기본값은 `false`이고, 기존 설정 파일에 키가 없어도 기본적으로 NPC 방식이 적용됩니다.

```yaml
상점-명령어열기: true
```

일일 보상·송금·집·스폰 기능과 기존 QuickShop 유저 상자는 그대로 유지합니다. QuickShop은 NPC 상점의 필수 플러그인이 아닙니다. NPC 상점과 QuickShop 유저 상점은 서로 다른 거래 창입니다.

## 저장과 보호

NPC는 월드의 영속 엔티티이고 품목 구분은 엔티티의 영속 데이터에 기록합니다. 서버가 월드를 정상 저장하면 NPC가 함께 저장되며, 재시작 시 별도의 중복 생성 작업을 하지 않습니다. 새로 시작할 때 생성 명령을 다시 입력할 필요가 없습니다.

사람형 NPC는 위치를 고정하고, 주민형은 AI·중력·충돌을 끕니다. NPC의 피해·불·변신·차량 탑승과 기본 주민 거래창·장비 변경을 차단합니다. WorldGuard 등 다른 플러그인이 우클릭 이벤트를 먼저 막은 경우에는 그 취소를 존중합니다. NPC가 클릭되지 않으면 해당 지역의 상호작용 규칙을 확인하세요. 외부 엔티티 정리 플러그인이나 운영자 직접 삭제 명령까지 자동 복원하는 방식은 아닙니다.

## 버전·검증

- 대상 Paper API 버전은 `26.3`으로 지정합니다.
- 공식 Paper 현행 API에서 `MANNEQUIN`, `Mannequin.setImmovable`, `setDescription`과 클릭 이벤트·영속 데이터 API를 확인했습니다. 26.3 전용 브랜치를 조회하지 못해 현행 `main` 소스를 참고했습니다.
- 경제 검사 33개와 NPC 검사 29개를 오프라인으로 통과했습니다. Vault API는 실제 공식 JAR, Bukkit은 로컬 최소 시그니처 fixture를 사용합니다. fixture는 배포 JAR에 포함하지 않습니다.
- **Paper 26.3에서 NPC 외형·우클릭·월드 저장을 실제 실행해 확인하지는 못했습니다.** 설치 후 NPC 생성·거래·정상 종료/시작을 한 번 확인하세요.
- 기존 EssentialsX 2.22.0의 26.3 미지원 문제를 해결하는 업데이트는 아닙니다. 본체·스폰은 이전에 안내한 26.3 지원 공식 개발 빌드로 교체해야 합니다. 이번 ZIP에는 EssentialsX나 다른 공식 플러그인을 다시 넣지 않았습니다.
