# 한글 생활 경제 명령어

닉네임·직접 정한 집이름·영역이름·파일이름에는 실제 값을 입력합니다. 원래 영어 명령은 유지하지만 생활 플레이와 안내에는 아래 한글 명령을 사용할 수 있습니다.

| 명령어 | 기능 |
| --- | --- |
| `/메뉴` 또는 쉬프트+F | 생활 메뉴 |
| `/한글명령어`, `/경제안내` | 도움말 |
| `/돈`, `/잔액` | 내 잔액 |
| `/돈순위` | 잔액 순위 |
| `/송금 닉네임 금액` | 돈 보내기 |
| `/상점` | 서버 매입·판매 상점 |
| `/일일보상` | 하루 한 번 보상 |
| `/집저장` | 기본 집 저장 |
| `/집` | 기본 집 이동 |
| `/집저장 집이름`, `/집 집이름` | 이름 있는 집 저장·이동(권한에 따라 제한) |
| `/집삭제 집이름` | 집 삭제 |
| `/스폰` | 마을 이동 |
| `/이동요청 닉네임` | 그 사람에게 이동 요청 |
| `/소환요청 닉네임` | 내 위치로 초대 |
| `/이동수락`, `/이동거절`, `/이동취소` | 요청 처리 |
| `/이전위치` | 이전 위치 이동(별도 권한 필요) |
| `/귓속말 닉네임 내용`, `/답장 내용` | 개인 메시지 |
| `/접속자` | 접속 인원 |

## 유저 거래소

거래할 아이템을 들고 상자를 바라본 뒤 사용합니다. `/거래소` 또는 `/거래소 도움말`로 한글 안내를 봅니다.

| 명령어 | 기능 |
| --- | --- |
| `/거래소 생성 가격` | 상자 상점 생성 |
| `/거래소 가격 금액` | 가격 변경 |
| `/거래소 수량 개수` | 묶음 수량 변경 |
| `/거래소 판매` | 유저에게 물건 판매 |
| `/거래소 매입` | 유저의 물건 구매 |
| `/거래소 이름 새이름` | 상점 이름 변경 |
| `/거래소 삭제` | 내 상점 제거 |
| `/거래소 직원 추가 닉네임` | 직원 등록 |
| `/거래소 직원 삭제 닉네임` | 직원 해제 |
| `/거래소 직원 목록` | 직원 확인 |
| `/거래소 직원 전체삭제` | 직원 전체 해제 |
| `/거래소 기록` | 거래 기록(권한 필요) |
| `/거래소 둘러보기` | 상점 조회(권한 필요) |
| `/거래소 양도 닉네임` | 양도 요청(권한 필요) |
| `/거래소 양도 수락`, `/거래소 양도 거절` | 양도 요청 처리 |
| `/거래소 즐겨찾기`, `/거래소 관심` | 상점 표시(권한 필요) |

상점 화면 버튼은 원래 플러그인의 명령을 내부에서 실행합니다. 수동으로 사용할 때는 위 한글 별칭을 사용하세요.

## GriefPrevention 설치 시

이 추가 플러그인이 실제로 활성화되어야 작동합니다. 금 삽으로 대각선 두 모서리를 우클릭해 땅을 지정합니다.

| 명령어 | 기능 |
| --- | --- |
| `/땅목록`, `/땅확인` | 내 땅 확인 |
| `/땅초대 닉네임` | 건축 권한 부여 |
| `/땅추방 닉네임` | 건축 권한 회수 |
| `/땅권한` | 땅 권한 목록 |
| `/땅포기` | 현재 땅 보호 해제(신중히 사용) |
| `/땅구매 수량`, `/땅판매 수량` | 보호 블록 거래(서버 설정에 따라 제한) |

## 운영자·건축

| 명령어 | 기능 |
| --- | --- |
| `/스폰설정` | 서버 스폰 지정 |
| `/경제설정 새로고침` | 가격·보상 설정 반영 |
| `/돈관리 지급 닉네임 금액` | 돈 지급 |
| `/돈관리 회수 닉네임 금액` | 돈 회수 |
| `/돈관리 설정 닉네임 금액` | 잔액 설정 |
| `/플러그인목록`, `/서버정보` | 설치·버전 확인 |
| `/권한 사용자 닉네임 권한 설정 권한키 참` | LuckPerms 권한 설정(설치 시) |
| `/권한 그룹 그룹이름 권한 설정 권한키 거짓` | 그룹 권한 거부(설치 시) |
| `/블록조사` | CoreProtect 조사 도구(설치 시) |
| `//도끼`, `//첫점`, `//둘째점` | WorldEdit 선택 |
| `//채우기 돌`, `//바꾸기 흙 잔디블록` | 선택 영역 편집 |
| `//복사`, `//붙여넣기`, `//되돌리기` | 건축 편집 |
| `/영역 생성 마을` | WorldGuard 지역 생성 |
| `/영역 설정 마을 피브이피 거부` | 지역 전투 차단 |

권한 키처럼 플러그인이 해석하는 내부 값은 원래 값을 씁니다. 각 명령의 권한 검사는 연결된 공식 플러그인이 수행하며, 관리 명령은 일반 유저에게 개방하지 않습니다.
