# 도시 농장 리소스팩

5개 작물의 수확물·씨앗·요리 15개 아이콘과 4단계 성장 모델 20개를 기존 도시팩에 합칩니다. 사용자 분위기 선호인 현실적인 도시·경제풍의 포장/음식 아트입니다. 원본 생성 아틀라스는 `art/`에 보존하고 `개발자료/공통도구/build.py`로 게임용 셀 추출·크기 조정·모델 생성·ZIP 포장을 합니다.

대상은 Minecraft Java 26.3, 리소스 형식 97.1입니다. item_model을 이용하므로 기본 밀이나 사과 텍스처를 전역 교체하지 않습니다. 작물은 투명 텍스처를 두 교차 면으로 배치한 디스플레이 모델입니다. 씨앗·수확물·요리는 64×64이며, 실제 클라이언트 화면은 별도로 확인해야 합니다.
