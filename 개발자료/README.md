저장소 최상위의 `저장소구조.json`에 이전 경로와 새 한글 경로를 기록했습니다. 빌드·검사 도구는 이 파일을 기준으로 저장소를 찾습니다. Java 클래스명, 패키지명, `plugin.yml`, `config.yml`, 팩 내부 식별자처럼 프로그램이 사용하는 이름은 유지합니다. `README.md`는 GitHub에서 폴더 안내를 자동 표시하기 위해 유지합니다.

현재 클라우드 도구 기준 검사:

```bash
python3 개발자료/플러그인/생활경제/test_domain.py
python3 개발자료/공통도구/test_tycoon_integration.py
python3 개발자료/플러그인/마을상점/test.py
python3 개발자료/플러그인/커스텀농사/test.py
python3 개발자료/플러그인/아이템도감/test.py
python3 개발자료/플러그인/도시화면/test.py
python3 개발자료/배포도구/마을상점/build.py
python3 개발자료/공통도구/한글배포/묶음만들기.py
```

검사 환경과 실제 Windows/게임 검증의 차이는 각 기능의 검증 문서에 구분합니다. 기존 배포 파일은 `releases`의 원본을 사용하고, 한글 설치 파일은 `설치파일`에서 제공합니다.

현재 마을·상점 빌드 결과는 `.build/마을상점-빌드`에 생성합니다. `CIVIC_OUTPUT`으로 다른 새 출력 폴더를 지정할 수 있습니다. 원본 `releases`의 과거 배포를 덮어쓰지 않습니다.
