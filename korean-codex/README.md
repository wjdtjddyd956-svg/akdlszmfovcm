# 아이템 도감·수집 업적 1.0.1

기존 도감 코드를 보완한 Windows / Paper 26.3 build 238용 플러그인입니다. 8개 분야 80종·12업적, 실제 기본 아이템 1개 소비와 UUID 영구 저장, 작은 속성 보너스와 개인 토글을 제공합니다. 기존 경제·직업·강화·집·땅·KoreanMenu JAR를 교체하지 않습니다.

- [80종 보너스 표·업적 보상](../releases/korean-codex/1.0.1/아이템별보너스.md)
- [실제 Windows 적용·Paper·순정 클라이언트·모의 검사 구분](../releases/korean-codex/1.0.1/검증결과.md)

일반 대비 고급 2배·희귀 4배·전설 8배입니다. 드래곤 알은 제외합니다. 전체 상한은 이동 3%, 채굴 6%, 체력 +2HP, 공격력 +0.5, 방어 +1, 공격 속도 2%, 넉백 저항 2%p, 행운 +0.5입니다.

`/도감`, `/도감 등록`, `/업적`, `/도감효과 켜기|끄기`와 기존 쉬프트+F 수첩의 빈 20·26번 칸을 사용합니다. 기존 장비·물약·속성 기본값을 유지하고 도감 전용 임시 수정자만 추가/제거합니다. 체력 보너스 획득·토글로 즉시 회복시키지 않습니다.

등록은 소비 전후 플레이어 저장과 SQLite 저널을 사용합니다. 불확실한 결과와 알 수 없는 저장 표식은 영구 확인 대기로 잠그며 자동 재소비·환불·확정을 하지 않습니다. 관리자 조회·수동 정리·DB 스냅샷을 제공합니다. DB v1→v2에서도 기존 자료를 보존합니다.

`windows.py build`는 설치된 실제 API와 JDK 27, `windows.py test`는 MockBukkit 하네스용 JDK 25를 사용합니다. 검증된 Windows 설치·패키징과 테스트 재현 절차는 위 문서를 참고하세요. 1.0.0의 Linux/클라우드 빌드 파일·배포물은 이력으로 보존했습니다. SQLite 원본 드라이버/라이선스를 포함하며 추가 리소스팩·Vault가 필요하지 않습니다.
