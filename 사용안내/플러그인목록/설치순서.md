# 설치 순서와 운영 기준

마을·필지·개인상점 추가 구성은 [별도 안내](마을·개인상점.md)를 먼저 확인하세요. 해당 새 버전은 아직 Windows 운영 서버에 적용하지 않았습니다. 아래 문서는 이전 연결 구성의 기록입니다.

1. 최신 main·실제 plugins 식별자·버전·SHA-256을 대조합니다. 기존 호환 EssentialsX/Spawn과 16종을 유지합니다.
2. [46종 검토](../../개발자료/플러그인/서버연결/46종검토.md)로 중복·대안·유료 파일을 제외합니다.
3. [설치 안내](../../개발자료/플러그인/서버연결/설치안내.md)에 따라 공식 5개 파일·자체 연결 JAR·한국어 설정을 검사합니다.
4. 기존 ServerStop.cmd로 Paper와 Windows 백업 관리자를 정상 종료하고 전체 백업·파일별 SHA-256을 검증합니다.
5. 새 6개 JAR만 추가합니다. 원본 설정은 백업하며, 중복 이름·다른 빌드·사용자 수정 설정을 자동 덮어쓰지 않습니다.
6. 기존 ServerStart.cmd로 시작하여 권한·실제 표시값·기존 NPC/메뉴·팩 실패·재접속·재시작을 검사합니다.
7. 기존 건축·집·땅이 경계 안에 포함되는지 확인한 뒤 오버월드 경계·제한된 초기 Chunky 영역을 설정합니다. 경계 전체 생성과 구분합니다.
8. 기존 백업 관리자로 새 구성의 종료·백업·재시작을 확인합니다. 가방 복원은 판매·도감 소비·농사 영수증과 함께 검토합니다.

현재 실행 결과와 미완료 항목은 [검증결과](../../개발자료/플러그인/서버연결/검증결과.md)를 확인하세요. 단순 링크 응답·JAR 로드 성공을 모든 게임 동작 검증으로 부르지 않습니다. /reload·2.22.0 다운그레이드·보호 데이터 초기화를 하지 않습니다.
