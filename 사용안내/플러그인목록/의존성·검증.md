# 의존성·26.3 검증 근거

마을·필지·개인상점 추가 구성은 [별도 안내](마을·개인상점.md)를 먼저 확인하세요. 해당 새 버전은 아직 Windows 운영 서버에 적용하지 않았습니다. 아래 문서는 이전 연결 구성의 기록입니다.

| 정확한 배포판 | 필수 연결 | 검증 근거·한계 |
| --- | --- | --- |
| LuckPerms Bukkit 5.5.91 (build1678) | 로더가 공식 내부 라이브러리 설치, H2 저장 | 실제 Paper238 활성화·등급 상속/회수·기존 Bukkit 권한·재시작 검사 |
| Chunky Paper 1.5.66 | 별도 필수 플러그인 없음 | 공식 Modrinth 배포 메타데이터 26.3, 실제 작은 영역·운영 초기 반경512 작업 완료 기록 확인 |
| PlaceholderAPI 2.12.3 | 자체 표시 확장은 KoreanServerBridge | 공식 릴리스는 26.2 실험 지원 안내. 26.3 공식 보장을 주장하지 않음. 선택 배포판을 실제 Paper238에서 표시·재시작 검사 |

추가 ProtocolLib·PacketEvents·Citizens는 이 조합의 필수 의존성이 아닙니다. 기존 NBTAPI는 유지합니다. Prism을 CoreProtect로 바꾸지 않습니다. ViaVersion/ViaBackwards는 복제 서버 자동 클라이언트용으로만 사용했고 운영·설치 묶음에서 제외했습니다.

정확한 URL·파일명·SHA-256·소스·라이선스는 [versions.json](../../releases/plugin-integration/1.0.0/versions.json), 실제 검사 구분은 [검증결과](../../개발자료/플러그인/서버연결/검증결과.md)를 보세요. 다른 빌드의 호환성까지 일반화하지 않습니다. 남은 25종은 [46종 검토](../../개발자료/플러그인/서버연결/46종검토.md)의 제외·보류 사유를 따릅니다.
