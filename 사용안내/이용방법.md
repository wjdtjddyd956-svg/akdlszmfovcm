# 한글 명령어와 이용 방법

대부분의 기능은 **쉬프트+F → 마을 수첩**에서 시작합니다.

| 메뉴·명령어 | 할 수 있는 것 |
| --- | --- |
| `/메뉴` | 쉬프트+F와 같은 메인 메뉴 |
| `/마을` | 마을 설립·영역 확장·필지 분양·땅 매매 |
| `/마을 설립 이름` | 지정한 이름으로 설립 확인 화면 |
| `/마을 확장` | 현재 청크를 인접 마을 영역으로 확장 |
| `/마을 필지` | 분양·판매 중인 필지 목록 |
| `/개인상점` | 이용자가 등록한 물품 목록 |
| `/개인상점 등록 가격 수량` | 손에 든 물품의 묶음 가격·수량 설정 |
| `/개인상점 내판매` | 미판매 물품 확인·회수 |
| `/개인상점 대금` | 물품·필지 판매대금 받기 확인 |
| `/도감` · `/업적` | 아이템 등록과 작은 영구 보너스 확인 |
| `/농사` | 딸기·토마토·옥수수·쌀·오이 농장 안내 |
| `/땅보호` | 기존 개인 땅 보호와 친구 초대 안내 |
| `/도시팩 메뉴미리보기` | 통합팩 아이콘과 설치 안내 |

필지 1개는 16×16 청크입니다. 기본 마을 설립비 10,000원, 확장비 2,500원, 마을당 최대 16필지이며 설정에서 바꿀 수 있습니다. 개인상점의 가격은 **선택한 수량 전체의 가격**입니다. 판매 전에 물품과 금액을 확인하세요.

NPC 상점·직업·요리·임무·집·스폰은 기존 메뉴와 서버 설정을 사용합니다. 외부 플러그인 기능은 해당 플러그인이 설치·활성화돼 있어야 합니다.

운영자용 미확정 거래 정리는 `/마을거래`입니다. 실제 잔액·물품을 대조한 뒤 [거래·복구 안내](../설치파일/01_마을상점/거래·복구안내.md)를 따르세요.
