# 설치 순서와 운영 기준

대상은 Windows · Paper 26.3 · 약 10명 생활 경제 서버입니다. 실제 Windows의 현재 설치 목록은 이번 정리 작업에서 조회하지 않았습니다. 예전 설치 기록과 최신 배포 파일을 구분합니다.

## 1. 기존 서버 보관

`ServerStop.cmd`로 서버와 자동 백업 관리자를 정상 종료합니다. 없으면 콘솔 `stop` 후 종료를 기다립니다. 같은 시점의 월드·플레이어·전체 plugins 폴더를 보관합니다. `KoreanEconomy/생활경제.db`, `KoreanCodex/도감.db`, 보호·상점·집 데이터와 설정 폴더를 지우지 않습니다.

## 2. 기존 기본 플러그인 확인

Vault와 경제 제공자, EssentialsX 본체와 Spawn, QuickShop, 땅 보호·기록 플러그인의 기존 호환 설치본을 확인합니다. EssentialsX 본체와 Spawn은 같은 호환 빌드를 사용합니다. 저장소의 예전 `vendor/EssentialsX-2.22.0.jar` 및 같은 버전 Spawn은 Paper 26.3 오류 이력이 있어 최신 설치 대상으로 사용하지 않습니다.

목록에 있는 SHA-256은 파일 동일성을 확인하는 값입니다. 해시가 맞는 것과 Paper 26.3의 모든 기능이 동작하는 것은 별개입니다. `연결·한글화.md`와 각 배포물의 검증 범위를 함께 읽습니다.

## 3. 최신 메뉴·도감·농장 적용

정리 묶음 ZIP을 **실제 서버 폴더 바깥**에 풉니다. `설치자료/도시생활UI/Install-Interface.cmd`를 실행하고 `server.properties`가 있는 실제 서버 폴더를 지정합니다.

기존 설치 도구는 잠금·파일·버전을 검사하고 전체 서버를 백업·검증한 뒤 **경제 2.0.2 / 메뉴 2.1.0 / 도시팩 1.1.0 / 농사 1.0.1 / 도감 1.2.0**의 5개 JAR를 교체합니다. 땅 보호·기록·Essentials·Vault·QuickShop 및 데이터 폴더는 기존 것을 유지합니다. 지원 대상은 생활타이쿤 2.0.1/2.0.2 서버입니다. 새 서버를 이 파일만으로 처음 구성하는 설치기는 아닙니다.

`설치자료/기존한글보조/`의 KoreanCommands·KoreanPackSetup 2.0.0은 기존 한글 보조 파일입니다. 이미 같은 버전을 쓰면 그대로 유지합니다. 필요해서 수동 교체할 때에는 먼저 전체 백업을 만들고 같은 플러그인의 이전 JAR만 서버 밖으로 옮겨 한 개씩 남깁니다. 이 두 파일은 위 5개 교체 설치기의 자동 대상이 아닙니다.

JAR는 파일명뿐 아니라 내부 `plugin.yml`의 플러그인 이름으로 중복을 확인합니다. 원본과 한글 수정 WorldEdit·WorldGuard를 동시에 넣지 않습니다. `sqlite-jdbc`, `slf4j`, `snakeyaml` 같은 개발·내장 라이브러리 JAR는 이 목록의 이용자 기능 플러그인이 아니며 plugins 폴더에 한꺼번에 복사하지 않습니다.

## 4. 재시작 후 확인

기존 `ServerStart.cmd`로 시작합니다. 접속 시 통합 리소스팩을 허용하고 쉬프트+F에서 도감·업적·농장·직업·요리·이동 메뉴를 확인합니다. 도감 등록 전후 수량, 실제 잔액, NPC 거래, 작물 심기·수확, 땅 보호를 일반 이용자 권한으로 확인합니다.

팩을 직접 설치했다면 Minecraft 설정에서 `CityEconomy-Interface-26.3-1.2.0.zip`을 선택하고 쉬프트+F → 메뉴 리소스팩 → 직접 설치 확인을 누릅니다. 거절·실패해도 기본 메뉴로 접속을 유지합니다. 새 메뉴 설정은 `plugins/CityTextures/ui.yml`에 있습니다.

## 5. 추가 후보의 적용 순서

| 순서 | 후보 | 먼저 할 일 |
| --- | --- | --- |
| 1 | LuckPerms | 이용자·운영자 권한과 등급 이름 정리 |
| 2 | Chunky | 월드 경계와 생성 범위를 정한 뒤 지형 미리 생성 |
| 3 | PlaceholderAPI | 필요한 공식 확장과 자체 표시값 연결 범위 확인 |
| 4 | TAB | 한국어 탭·사이드바와 실제 잔액·직업·도감 표시 연결 |
| 5 | DecentHolograms | 상인·마을 안내 문구와 위치 설정 |
| 6 | BetterRTP | 야생 입장 NPC·허용 월드·위험 지형 정책 연결 |
| 필요 시 | 나머지 콘텐츠·접속 확장 | 실제 배포판·필수 의존성·언어 설정·기존 기능과 충돌 검증 |

위 후보는 이번 묶음에 신규 JAR를 넣거나 설치한 상태가 아닙니다. 공식 배포판과 Paper 26.3 지원 여부를 선택한 뒤 서버 복사본에서 한 종류씩 적용해 확인합니다. 일반 유저의 메뉴와 안내를 한국어로 연결한 뒤 운영 서버에 반영합니다. 목록의 문서 한글화가 새 플러그인 내부 전체 번역을 뜻하지는 않습니다.

## 6. 기능별 선택 관계

- 개인 땅은 GriefPrevention, 운영 구역은 WorldGuard로 역할을 정합니다.
- 기존 기록·복구는 Prism을 유지합니다. CoreProtect는 대체 후보로 정리했으며 기존 Prism 기록을 자동 이전하지 않습니다.
- 기본 NPC 돈 상점·직업·일일 임무·농작물·도감은 자체 구성으로 사용합니다. Citizens와 퀘스트 도구는 추가 연출·스토리가 필요할 때 검토합니다.
- ItemsAdder·Nexo·Oraxen은 커스텀 콘텐츠 도구의 대안 후보입니다. 현재 5종 작물과 메뉴팩에 별도로 필수인 플러그인은 아닙니다.
- PacketEvents와 ProtocolLib은 실제 기능 제공 플러그인의 지원 조건에 맞춰 선택합니다. 설치만으로 QuickShop 상품 표시가 켜진다고 가정하지 않습니다.
- `/spark`가 이미 제공되면 해당 기능을 사용합니다. 광물 엑스레이 방지는 Paper의 기본 기능도 검토할 수 있습니다.
- 인벤토리 개별 복구는 도감 소비·판매·경제 거래 기록과 함께 확인합니다. 전체 복원은 같은 시점의 월드·플레이어·플러그인 자료로 진행합니다.
- ViaVersion·ViaBackwards·Geyser·Floodgate는 실제 접속 지원 범위와 커스텀 모델·팩 표시를 따로 확인합니다.

## 7. 외부 배포·계정 설정

외부 플러그인의 구매 파일·계정·디스코드 봇 토큰은 이 저장소나 ZIP에 넣지 않습니다. 공식 자료에서 배포 조건을 확인합니다. 원래 설정 키·플러그인 식별자·JAR 파일명은 의존성에 필요하므로 유지하고 이용자에게 보이는 이름·문구·메뉴를 한국어로 구성합니다.
