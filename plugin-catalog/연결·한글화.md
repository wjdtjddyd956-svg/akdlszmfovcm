# 실제 연결·한글화 범위

마을·필지·개인상점 추가 구성은 [별도 안내](마을·개인상점.md)를 먼저 확인하세요. 해당 새 버전은 아직 Windows 운영 서버에 적용하지 않았습니다. 아래 문서는 이전 연결 구성의 기록입니다.

문서 번역과 실제 내부 문구 번역을 구분합니다. 새 연결·설정은 [설치 묶음](../plugin-integration/README.md)에 있습니다. 한국어 메뉴·동적 TAB·마을 안내판은 실제 실행 검사했습니다. TAB/DH/PAPI 고급 운영 명령과 로그 일부는 영문입니다. LuckPerms는 공식 ko_KR 번들과 플레이어 클라이언트 언어 설정을 사용합니다.
