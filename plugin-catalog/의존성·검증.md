# 의존성·검증 범위

확인한 배포 JAR의 필수 의존 선언과 선택적인 연결 대상을 구분합니다. 추가 후보는 배포판·버전을 아직 선택하지 않았으므로 필수 의존성이 없다고 가정하지 않습니다. 실제 시작 순서는 서버가 플러그인 선언에 따라 처리합니다.
