# 생활 타이쿤 Windows 업그레이드 2.0.1

기존 생활서버 1.2 또는 2.0을 Paper 26.3 build 238에서 사용하는 Windows 전용 업그레이드입니다. 자체 요리·강화·숙련도·NPC 임무를 사용하며 원본 띵타이쿤의 비공개 코드·자산이나 채팅 변환을 포함하지 않습니다. 새 서버 설치는 기존 1.2 설치 안내부터 진행하세요.

## 설치

1. ZIP을 **서버 폴더 밖**에 압축 해제합니다. `plugins`에 JAR만 수동 복사하지 마세요.
2. `설치하기.cmd`를 실행하고 `server.properties`가 있는 서버 폴더를 입력합니다.
3. 설치기가 배포 JAR의 SHA-256을 확인하고 기존 `Stop-LifeServer.ps1`로 서버와 백업 관리자를 함께 정상 종료합니다. 전체 백업을 만들고 **모든 백업 파일의 해시를 검사한 뒤** 교체합니다. 실패하면 창의 오류를 확인하세요.
4. 원래 `ServerStart.cmd`로 실행합니다. 콘솔에서 KoreanEconomy 2.0.1과 나머지 자체 플러그인 2.0.0의 활성화를 확인합니다.
5. 게임에서 `/메뉴`, `/직업`, `/요리`, 도구를 든 상태의 `/강화`를 확인합니다. 상점·임무는 기존 NPC를 우클릭합니다.

교체 대상은 **KoreanEconomy → 2.0.1**, **KoreanMenu·KoreanCommands·KoreanPackSetup → 2.0.0**입니다. 파일명 대신 `plugin.yml`의 플러그인 이름으로 이전 JAR를 찾아 `tycoon-server-backups/교체전-JAR-*`로 이동합니다. 기존 Essentials 본체·Spawn, Vault, QuickShop JAR는 설치 준비에 그대로 재사용합니다. GriefPrevention·Prism·WorldEdit·WorldGuard·NBTAPI·기존 Windows 백업 관리자는 교체하지 않습니다.

호환 EssentialsX 본체·Spawn은 같은 빌드여야 하며 실제 26.3 지원 클래스도 검사합니다. 설치된 `2.22.1-dev+28-f8724e2`를 유지하며 2.22.0으로 내리지 않습니다. 미결 1.2 생활 거래가 있으면 설치를 중단합니다. 이전 버전에서 실제 잔액·가방을 확인해 `/경제거래`로 정리한 뒤 다시 설치하세요.

기존 설정 폴더·월드·잔액·집·스폰·NPC·GP 땅·QuickShop 상점은 유지합니다. `생활기록/*.properties`의 직업·숙련도·적립금·당일 판매량·임무 기록은 해당 UUID 접속 시 SQLite로 한 번 가져오며 원본을 삭제하지 않습니다. 이전에 수락한 오늘 임무는 게시판의 `이전 임무`에서 이어갑니다. 기존 일일 보상 기록도 가져옵니다. 신규 시작 잔액만 1,000원이며 기존 계정에 일괄 지급하지 않습니다.

## 플레이어 명령

| 명령 | 기능 |
|---|---|
| 쉬프트+F / `/메뉴` | 한글 마을 수첩 |
| `/돈`, `/돈순위`, `/송금 닉네임 금액` | 기존 Vault 잔액·송금 |
| `/집저장`, `/집`, `/집삭제`, `/스폰` | 기존 집·스폰 |
| `/직업` | 농부·광부·낚시꾼 선택, 레벨·숙련도·적립금 수령 |
| `/요리` | 실제 재료를 소비하는 요리 10종, 직업·레벨 해금 |
| `/강화` | 주 손의 도구 강화. 비용·성공률 확인 후 클릭 |
| `/임무` | 일일 임무 수락·진행·납품·완료 상태 |
| `/일일보상` | 한국 시간 자정 기준 일일 보상 |
| `/땅보호` | 기존 금 삽 땅 지정 안내 |
| `/땅보호 확인`, `목록`, `권한` | 소유자·범위·권한 확인. 막대기 우클릭으로 경계 표시 |
| `/땅보호 초대 닉네임`, `상자초대 닉네임`, `회수 닉네임` | 내 GP 땅의 건축·상자 권한 관리 |
| `/땅보호 해제 확인` | 현재 내 땅만 해제 |

농부는 다 자란 작물, 광부는 자연 광석, 낚시꾼은 직접 낚은 물고기로 적립합니다. 설치한 광석·피스톤으로 옮긴 블록·이미 채굴한 좌표의 재생 광석은 보상에서 제외합니다. 돌은 광부 숙련도만 줍니다. 직업별 숙련도는 유지하며 적립금은 Vault로 수령합니다. 기본 하루 적립 한도 300원, 숙련도 250입니다. 첫 직업 선택은 무료, 변경은 200원·30분 대기입니다.

강화는 5단계이며 실패 시 도구·단계를 유지하고 비용을 소비합니다. NPC 요리 매입은 마을 주방에서 만든 동일한 아이템만 받습니다. 이름을 붙인 일반 빵은 요리로 판매할 수 없습니다. 상점은 남은 개인별 매입량과 다음 초기화 시각을 표시합니다. 구매가보다 판매가를 높인 일반 상점 설정은 거부합니다.

일반 유저에게 OP·돈 생성·기록 조회·복구·NPC 배치 권한을 주지 않습니다. 경제 거래가 확인 대기로 남으면 해당 계정의 자체 거래를 막고 자동으로 재지급하지 않습니다. 운영자가 실제 Vault 잔액·가방·거래 내역을 확인한 뒤 `/경제기록 정리 거래번호 완료 확인` 또는 `취소 확인`으로 **기록 상태만** 정리합니다. Vault·플레이어 파일·SQLite가 하나의 분산 원자적 거래라고 보장하지 않습니다.

## 설정

먼저 원본 `plugins/KoreanEconomy/config.yml`을 복사해 백업하세요. 동봉 `설정예시`는 참고용이며 기존 파일을 통째로 덮어쓰지 마세요. 없는 새 항목에는 코드의 기본값을 사용합니다. 기존 가격·직업 적립·1.2 임무 보상은 유지합니다.

```yaml
요리:
  mill_bread: {매입가: 12, 하루매입한도: 64}
강화:
  '1': {비용: 1000, 성공확률만분율: 10000}
  '2': {비용: 2500, 성공확률만분율: 8500}
```

요리 ID는 `mill_bread`, `carrot_salad`, `roast_potato`, `mushroom_soup`, `pumpkin_pie`, `apple_jam`, `sweet_cookie`, `roast_cod`, `salmon_meal`, `golden_meal`입니다. 가격은 원 단위 정수 1~1,000,000, 매입 한도는 0~1,000,000입니다. 성공확률만분율 10000은 100%, 8500은 85%입니다. 기존 창은 닫고 다시 여세요. 요리·강화의 표시 금액과 실행 금액이 같은 설정에서 생성됩니다.

리소스팩은 필수가 아니며 기본 false를 유지합니다. 기존 2.0 배포의 선택 리소스팩은 별도로 사용할 수 있지만 이번 검증은 기본 아이콘으로 진행했습니다.

## 백업과 복원

기존 `life-tools/backup.json`에서 주기(`intervalHours`), 보관 개수(`keep`), 저장 위치(`directory`)를 정합니다. 기본 12시간·7개·서버 폴더 옆 `*-backups`입니다. 관리자는 저장·정상 종료 후 월드·플러그인·중요 설정의 차가운 스냅샷을 만들고, 서버를 다시 시작한 뒤 별도 작업에서 압축합니다. 실행 중 월드를 단순 복사한 백업이 아닙니다. 결과는 `life-control/status.txt`, `backup.log`와 `.sha256`에 남습니다.

**설치 전 전체 백업**은 위 예약 백업과 다른 형식입니다. `tycoon-server-backups/전체서버-날짜.zip`에 라이브러리까지 포함한 서버 파일 전체를 보관합니다. 자체 백업 폴더와 재생성되는 `session.lock`·설치 잠금 파일은 제외합니다. 파일별 SHA-256 목록 `TYCOON-SHA256.properties`가 들어 있습니다. 자동 삭제하지 않으므로 디스크 공간을 확인하고 다른 디스크에도 복사하세요.

전체 백업을 검증하거나 복원하려면 서버와 백업 관리자를 `ServerStop.cmd`로 종료한 뒤, 배포 폴더에서 실행합니다.

```text
java -Dstdout.encoding=UTF-8 -jar 설치도구.jar 검증 "전체서버-날짜.zip"
java -Dstdout.encoding=UTF-8 -jar 설치도구.jar 복원 "서버폴더" "전체서버-날짜.zip" --서버종료확인
```

복원은 현재 상태를 다시 전체 백업하고, 월드·돈·집·상점·기록을 **같은 시점으로** 되돌립니다. 새 버전에서 생긴 파일이 옛 복원에 섞이지 않도록 기존 최상위 폴더를 `tycoon-server-backups/복원전-*`로 보관합니다. 완료 후 원래 `ServerStart.cmd`를 사용하세요.

기존 예약 `life-*.zip`은 형식이 다릅니다. 먼저 `ServerStop.cmd`, 그다음 다음 명령을 사용합니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "서버폴더\life-tools\Restore-LifeBackup.ps1" -Archive "백업폴더\life-날짜.zip" -ServerDirectory "서버폴더"
```

이 형식은 `.sha256`과 내부 스냅샷 목록을 검사하며 복원 전 파일도 별도 폴더로 보관합니다. KoreanEconomy의 `/서버백업`은 DB·설정만 백업하는 보조 기능이므로 월드·Essentials와의 전체 복원에는 위 두 방식을 사용하세요.

총 RAM 16GB에서 현재 관리자의 최대 2GB 설정을 유지했습니다. 실제 10명 활동 부하 검증은 별도입니다. 게임 클라이언트·다른 앱을 함께 쓸 때 무조건 6GB로 높이지 말고 TPS·힙·운영체제 여유 메모리를 보고 조절하세요. 이번 실행은 기존 JDK 27이며 Paper 26.3의 기존 정상 구동 환경을 변경하지 않았습니다.
