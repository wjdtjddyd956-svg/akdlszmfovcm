# 기존 다운로드 주소 보관

이 폴더는 기존 서버 설정과 이미 배포한 링크가 계속 작동하도록 원래 경로와 파일을 보관합니다.

**설치할 파일은 [한글 설치파일 목록](../설치파일/README.md)에서 찾으세요.**

| 원본 자료 | 폴더 |
| --- | --- |
| 마을·개인상점 | [civic-update](civic-update/1.0.0) |
| 메뉴·도감 통합 | [ui-update](ui-update/1.2.1) |
| 서버 연결·한글 설정 | [plugin-integration](plugin-integration/1.0.0) |
| 농장 | [farming-update](farming-update) |
| 도시 리소스팩 | [city-resourcepack](city-resourcepack) |
| 아이템 도감 | [korean-codex](korean-codex) |
| 기존 생활타이쿤 | [tycoon-2.0.1](tycoon-2.0.1) |
| 초기 타이쿤 | [tycoon-2.0](tycoon-2.0) |
| 경제 야생 초기 묶음 | [survival-pack](survival-pack) |
| 한글 월드에딧·월드가드 | [korean-plugins](korean-plugins) |
| 한글 명령어 | [korean-commands](korean-commands) |
| 마을 지도 | [economy-spawn](economy-spawn) |
| 이전 플러그인 정리 묶음 | [plugin-catalog](plugin-catalog) |

기존 배포 파일의 내용은 변경하지 않았습니다. 이 폴더의 예전 문서에 나온 소스 경로는 [정리 전 버전](https://github.com/wjdtjddyd956-svg/akdlszmfovcm/tree/231e432)에서 확인할 수 있고, 현재 소스 위치는 [개발자료](../개발자료/README.md)와 [저장소 경로표](../저장소구조.json)에 있습니다.
