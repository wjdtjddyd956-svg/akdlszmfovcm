# 도시 생활 수첩 Windows 1.2.1

Paper26.3 build238 / Windows / Java25 이상. 기존 생활타이쿤2.0.1/2.0.2, 농장, 85종·13업적 도감의 자료를 이어받습니다. 새 경제·NPC·채팅 플러그인을 중복으로 만들지 않습니다.

## 무엇이 달라지나요

- 쉬프트+F의 경제/거래, 수집/농장, 이동/생활, 성장/직업을 일관된 위치와 색으로 구분합니다. 도감·업적·농장·직업·요리·상점 안내·집·스폰을 바로 찾을 수 있습니다.
- 아이콘에는 한국어 이름·설명·클릭 안내가 있습니다. 플러그인이 꺼져 있으면 준비 중으로 표시하고, NPC 상점 버튼은 실제 마을 NPC로 안내합니다.
- 도감의 전체/등록 가능/미보유/등록 완료 필터, 가방36칸의 실제 정품 수량, 분야 진행률·완료 강조, 업적의 남은 목표를 표시합니다. 장비·보조 손·이름 바꾼 물건은 등록 수량에서 제외합니다.
- 등록 확인창은 **아이템1개 소비**, 이번에 실제로 증가할 수치, 함께 달성할 업적을 보여줍니다. 상한에 도달했으면 증가한다고 표시하지 않습니다. 미결 거래·모드·권한 제한은 등록 가능과 구분합니다.
- 도감 화면의 이전/마을 수첩 버튼, 농장·직업 등 빈47번 칸의 마을 수첩 복귀, 팩 미리보기 복귀를 제공합니다. 기존 기능 버튼을 덮어쓰지 않습니다.
- 기존 도시 아이콘32종·농장 아이콘15종·성장모델20종에 메뉴/도감/능력치 아이콘24종을 합쳤습니다. 201개 기존 에셋 파일은 원본과 바이트가 같습니다.
- 접속 시 통합팩을 한 번 요청합니다. 거절·실패해도 접속과 기본 메뉴를 유지하며, 열린 미리보기/농장 아이콘도 성공·실패 상태에 맞춰 갱신합니다. 별도로 확인된 농장팩 준비 상태는 유지합니다.

## 초보자용 Windows 설치

1. `도시생활-Windows-메뉴통합-1.2.1.zip`을 **기존 서버 폴더 바깥**에 압축 해제하세요. `plugins`나 월드 폴더를 통째로 갈아끼우지 마세요.
2. `Install-Interface.cmd`를 실행하고 `server.properties`가 있는 기존 서버 폴더 경로를 입력하세요. 예: `C:\Users\wjdtj\Downloads\버킷-실행파일-1\버킷-실행파일`.
3. 설치기가 도구와 JAR의 SHA-256을 확인한 뒤 **기존 ServerStop.cmd로 Paper와 Windows 백업 관리자를 정상 종료**합니다. 종료 파일이 없거나 종료에 실패하면 중단합니다.
4. 버전·중복 JAR·잠금을 검사하고 전체 서버 ZIP을 백업하여 모든 파일의 SHA-256을 검증합니다. 이 단계가 성공해야 플러그인을 교체합니다. 백업은 `서버폴더/tycoon-server-backups/전체서버-날짜.zip`, 이전 JAR는 같은 폴더의 `교체전-JAR-날짜`에 보존합니다.
5. 기존 `ServerStart.cmd`로 시작하세요. `/reload`를 사용하지 마세요. 아래 버전이 한 개씩만 활성화되어야 합니다.

| 플러그인 | 설치 버전 | 적용 |
|---|---|---|
| KoreanMenu | 2.1.0 | 이전 메뉴 교체 |
| KoreanCodex | 1.2.1 | 이전 도감 교체, 기존DB 유지 |
| KoreanFarming | 1.0.2 | 기존 농장·보상 보존, 통합팩 준비/명령어 없는 회수 유지 |
| CityTextures | 1.1.1 | 신규 또는 이전 보조 플러그인 교체 |
| KoreanEconomy | 2.0.2 | 동일 SHA-256이면 설치된 JAR를 그대로 재사용 |

설치기는 파일명 대신 `plugin.yml`의 이름으로 기존 JAR를 찾습니다. 알 수 없는 더 새로운 버전·중복 JAR는 덮어쓰지 않습니다. EssentialsX 본체/Spawn·Vault·GriefPrevention·Prism·QuickShop·WorldEdit/WorldGuard·Windows 백업 관리자는 교체하지 않습니다.

처음 CityTextures를 추가하면 `config.yml`과 `ui.yml`을 자동 생성합니다. 기존 설정이 있으면 유지합니다. `ui.yml`의 `사용`, `접속시-요청`, `팩-주소`, `체크섬-SHA1`을 확인하세요. 기본 통합팩 SHA1은 `e76e2c98f7659c07cea00050ca87edf88267af7e`입니다. 설정 참고 파일도 ZIP에 넣었으며 기존 파일 위로 무조건 복사하지 마세요.

## 접속 후 이용

팩 허용 → 쉬프트+F → 아이템 도감 → 분야 → 등록 가능 → 아이템 → **1개 소비와 실제 보상 확인** → 확인. 등록 후 분야 진행률이 바뀝니다. 등록 완료 필터는 다시 소비하지 않습니다. 업적 버튼에서 남은 목표, 내 수집 효과에서 적용량·전체 상한·켜기/끄기를 확인하고 **마을 수첩**으로 돌아옵니다.

팩을 거절해도 추방하지 않습니다. 쉬프트+F → **메뉴 리소스팩**에서 미리보기·다시 받기·직접 설치 확인을 이용합니다. Minecraft가 이전 거절을 기억하면 서버 목록 → 서버 선택 → 편집 → 서버 리소스 팩을 **물어보기/사용**으로 바꾸고 재접속하세요.

직접 설치는 `resourcepacks/CityEconomy-Interface-26.3-1.2.0.zip`을 Minecraft의 리소스팩 폴더에 넣고 활성화한 뒤 메뉴의 **직접 설치 확인**을 누릅니다. 서버가 클라이언트 파일을 자동 검사하는 기능은 아니므로 실제 적용한 뒤 눌러주세요. 예전 도시팩의 확인 기록과 새 통합팩의 확인은 구분됩니다. Complete ZIP은 도시 건축 재질8종까지 바꾸는 선택 사항입니다. 서버에서 Complete를 요청하려면 그 ZIP의 실제 SHA1과 주소를 함께 바꾸세요.

농산물·잡화 NPC 우클릭 → 농장 상점 → 씨앗 구매 → 젖은 경작지에 심기 → 우클릭 수확 흐름은 유지됩니다. `/농사`를 입력해야 시작하는 방식이 아닙니다. 쉬프트+우클릭으로 회수 확인창을 엽니다.

## 백업·복원

기존 `/백업 지금`은 Windows 관리자에게 월드 포함 냉백업을 요청합니다. 관리자는 저장·정상 종료 후 같은 시점의 월드와 플러그인 데이터를 스냅샷으로 만들고 재시작하며 압축은 별도 작업으로 수행합니다. 기존 주기·보관 개수·저장 경로는 `life-tools/backup.json`을 유지합니다. `/서버백업`은 경제DB·설정 스냅샷이며 월드·Vault 전체 백업과 다릅니다.

설치 전 전체 백업 검증: `java -jar InterfaceInstaller.jar 검증 "전체서버-날짜.zip"`.

복원은 먼저 `ServerStop.cmd`로 서버와 관리자를 종료한 뒤 `java -jar InterfaceInstaller.jar 복원 "서버폴더" "전체서버-날짜.zip" --서버종료확인`을 실행합니다. 도구는 백업을 검증하고 복원 직전 서버도 백업한 다음 전체 트리를 복원해 백업 이후 새 파일이 끼어 남지 않게 합니다. 기존 관리자 주기 백업 ZIP은 해당 `Restore-LifeBackup.ps1`을 사용하고 설치기 백업 형식과 혼용하지 마세요.

도감·거래 확인 대기 기록을 삭제하거나 자동으로 재지급하지 않습니다. 기존 `/도감관리 거래`, `/농사관리 거래`로 실제 아이템·잔액·저장 상태를 확인한 뒤 운영자가 정리하세요. 메뉴 필터·아이콘만 여는 작업으로 돈이나 아이템을 만들지 않습니다.
