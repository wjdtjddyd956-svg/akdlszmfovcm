ZIP은 클라이언트 리소스팩 폴더, JAR 한 개는 서버 plugins 폴더에 넣습니다. 서버와 기존 백업 관리자를 종료하고 JAR를 추가한 뒤 재시작하세요. 팩을 선택한 이용자는 `/도시팩 켜기`, `/도시팩 미리보기`로 확인합니다. 기존 경제·임무·집·땅 데이터와 2.0.1 운영 변경은 계속 사용합니다.

64×64 아이콘, 128×128 건축 재질. 모델·이미지·ZIP 검사 444개, 실제 Paper API 컴파일 및 MockBukkit 16개, 로컬 Chromium 미리보기 검사 9개를 통과했습니다. 실제 Minecraft 클라이언트 렌더링과 Windows 서버 설치는 미검증입니다. `validation.json`과 `build-info.json`에 범위를 기록했습니다.
