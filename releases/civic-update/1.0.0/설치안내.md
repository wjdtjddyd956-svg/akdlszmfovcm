# 마을·필지 매매 + 개인상점 1.0.0

[설치 ZIP](https://github.com/wjdtjddyd956-svg/akdlszmfovcm/raw/refs/heads/main/releases/civic-update/1.0.0/도시생활-마을상점-1.0.0.zip) · [화면 미리보기](메뉴-미리보기.png) · [거래 복구·개발 검증](거래·검증.md)

쉬프트+F → **마을·땅 거래**에서 마을 설립 → 영역 확장 → 필지 분양 → 땅 구매·재판매를 이용합니다. 쉬프트+F → **개인상점**에서는 실제 물품을 등록하고 다른 이용자가 구매합니다. 자체 화면·메시지·이용자 명령은 한글입니다.

## 설치

대상은 기존 생활 경제 서버 Paper **26.3 build238(df120fd)** / Java **25 이상**입니다. Vault와 기존 경제 제공자가 필요합니다. 이 묶음은 기존 서버용 업데이트입니다. 신규 서버 전체 설치팩은 아닙니다.

1. ZIP을 **서버 폴더 밖**에 압축 해제합니다.
2. `Install-Civic.cmd`를 실행하고 `server.properties`가 있는 서버 폴더를 선택합니다. `ServerStop.cmd`가 있으면 정상 종료를 실행합니다. 없으면 콘솔에 `stop`을 입력해 완전히 종료한 뒤 설치창에 `종료확인`을 입력합니다.
3. 설치기는 파일 해시·플러그인 버전·서버 잠금을 확인하고 **전체 서버 백업을 검증한 뒤** 아래 6개 JAR를 설치합니다. 같은 플러그인의 예전 JAR는 파일명에 관계없이 교체하며, 동일한 파일은 다시 쓰지 않습니다.
4. 기존 실행기로 시작하고 `/plugins`에 KoreanCivic가 활성화됐는지 확인합니다. 쉬프트+F의 두 버튼으로 이용합니다. 기존 통합팩을 이미 적용했다면 그대로 사용합니다. 처음이라면 통합팩 요청을 허용하거나 ZIP의 `resourcepacks`에서 직접 설치합니다.

| 플러그인 | 버전 | 변경 |
| --- | --- | --- |
| KoreanEconomy | 2.0.3 | 마을 필지 보호·공유 거래 기록·DB 스키마 2 |
| KoreanMenu | 2.2.0 | 마을·땅 거래 / 개인상점 입구 |
| CityTextures | 1.2.0 | 새 화면 아이콘 연동·실제 물품 모델 보존 |
| KoreanCivic | 1.0.0 | 마을·필지·물품 보관·판매대금 |
| KoreanFarming | 1.0.2 | 최신 검증 배포 파일 그대로 포함 |
| KoreanCodex | 1.2.1 | 최신 검증 배포 파일 그대로 포함 |

기존 잔액·집·직업·농장·도감·NPC·QuickShop·개인 땅·설정 폴더는 초기화하지 않습니다. EssentialsX·Vault·WorldEdit·WorldGuard·GriefPrevention·Prism·서버 연결 모듈 등 다른 JAR도 교체하지 않습니다. 기존 개인 땅 보호는 쉬프트+F 왼쪽 아래 **기존 개인 땅 보호** 또는 `/땅보호`에서 사용합니다. 기존 상자 상점은 `/거래소`로 이용합니다.

수동으로 설치기를 실행할 때는 서버 종료 후 아래 명령을 사용합니다. 경로는 실제 값으로 바꾸세요.

```powershell
java -jar CivicInstaller.jar 마을설치 "C:\서버폴더" ".\plugins" --서버종료확인
```

## 마을·땅 거래

- **마을 설립**: 기본 10,000원. 현재 서 있는 16×16 청크 1개가 포함됩니다. 한 사람당 마을 1개를 설립할 수 있습니다. 기본 이름은 닉네임+마을이며 `/마을 설립 이름`으로 지정할 수도 있습니다.
- **영역 확장**: 마을 설립자가 같은 월드의 인접 청크에 서서 확정합니다. 대각선은 제외하며 기본 2,500원, 마을당 최대 16필지입니다. `F3+G`로 청크 경계를 볼 수 있습니다.
- **필지 분양·재판매**: 내 필지에서 가격을 정해 등록합니다. 설립자가 처음 분양하는 것과 구매자가 다시 판매하는 절차가 같습니다. 구매자가 확정하면 판매자의 필지 권한을 회수하고 새 소유자에게 넘깁니다. 일반 건물·상자 내용물은 땅에 남으므로 필요한 물건은 판매 전에 옮기세요.
- **기존 보호 존중**: 개인 땅과 WorldGuard 관리 영역에 겹쳐 생성하지 않습니다. 기존 보호를 자동으로 삭제하거나 마을로 전환하지 않습니다. 월드 경계와 경제 설정의 금지 월드도 지킵니다.
- **커스텀 작물**: 필지 안에 등록된 커스텀 작물이 남아 있으면 분양 등록·구매를 거절합니다. 먼저 수확하고 쉬프트+우클릭으로 회수하세요. 판매 취소는 작물이 있어도 가능합니다.

필지 전체 높이에 기존 경제 모듈의 보호를 적용합니다. 건축·상자·호퍼·피스톤·물 흐름·폭발 등을 보호하며 기존 `/땅보호` 친구 초대 권한은 소유자별로 이어집니다. 운영자의 기존 보호 우회 권한은 유지됩니다. 마을 소유권 전체 매매·주민 등급·세금·유지비·자동 건축·마을 삭제 기능은 이번 범위에 없습니다.

## 개인상점

1. 판매할 물건을 **주 손**에 듭니다.
2. 쉬프트+F → 개인상점 → **손에 든 물품 등록**을 누릅니다.
3. 수량과 **선택한 묶음 전체 가격**을 정하고 확인합니다. 등록한 수량만 가방에서 빼서 보관합니다.
4. 다른 이용자는 목록에서 물건·수량·가격·판매자를 확인하고 구매합니다. 판매자가 접속하지 않아도 구매할 수 있습니다.
5. 판매자는 **내 판매 관리**에서 미판매 물품을 회수하고, **판매대금 받기**에서 필지·물품 판매 적립금을 지갑으로 받습니다.

물품은 인챈트·내구도·이름·커스텀 농작물 식별 정보를 포함해 보관합니다. 구매·회수 때 가방 공간이 부족하면 돈을 차감하거나 물건을 바닥에 떨어뜨리지 않습니다. 한 번에 한 묶음 전체를 구매합니다. 기본 판매 한도는 인당 20건 / 서버 500건, 거래 금액은 1~1,000,000원입니다. 수수료·자동 만료는 없습니다.

| 명령 | 기능 |
| --- | --- |
| `/마을` | 마을·땅 거래 메뉴 |
| `/마을 설립 이름` | 지정한 이름으로 설립 확인 화면 |
| `/마을 확장` | 현재 청크 확장 확인 화면 |
| `/마을 필지` | 분양·판매 필지 목록 |
| `/개인상점` | 전체 물품 목록 |
| `/개인상점 등록 가격 수량` | 정확한 가격·수량으로 등록 설정 화면, 아직 확정하지 않음 |
| `/개인상점 내판매` | 내 판매·회수 |
| `/개인상점 대금` | 판매대금 받기 확인 화면 |

## 설정·권한·복원

첫 실행에 `plugins/KoreanCivic/config.yml`을 만듭니다. 설립비·확장비·필지 한도·판매 등록 한도·최대 금액을 원 단위로 바꾼 뒤 **서버를 완전히 재시작**하세요. 금액 범위는 최대 100만 원, 마을 필지는 1~256개입니다. `/reload`는 사용하지 마세요. 이용자 권한 `koreancivic.use`는 기본 허용, 거래 정리 권한 `koreancivic.admin`은 기본 OP입니다. OP가 아닌 운영진에게 필요하면 해당 권한만 별도로 부여하세요.

마을·개인상점 데이터는 기존 `plugins/KoreanEconomy/생활경제.db`의 `civic_*` 테이블에 저장됩니다. Core 스키마는 1→2로 올라갑니다. **예전 경제 JAR만 되돌리면 안 됩니다.** 복원은 서버 종료 후 설치기의 `복원`으로 월드·잔액·가방·DB를 같은 시점의 전체 백업으로 함께 되돌립니다.

```powershell
java -jar CivicInstaller.jar 복원 "C:\서버폴더" "C:\서버폴더\tycoon-server-backups\전체서버-날짜.zip" --서버종료확인
```

현재 배포는 클라우드에서 실제 Paper API 컴파일·MockBukkit·실제 SQLite·설치기 파일 검증을 수행했습니다. **이번 마을·개인상점 버전을 Windows 운영 서버에 적용하거나 실제 Minecraft 클라이언트로 플레이한 상태는 아닙니다.** 이전 농사·메뉴 버전의 Windows 검증 기록과 이번 결과를 구분합니다.
