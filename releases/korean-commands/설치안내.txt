KoreanCommands 1.0.0 설치 안내

필수 플러그인
- WorldEdit 7.4.6
- WorldGuard 7.0.21

설치 방법
1. 서버 콘솔에 stop을 입력하여 서버를 완전히 종료합니다.
2. 서버 폴더 전체를 백업합니다.
3. KoreanCommands-1.0.0.jar를 서버의 plugins 폴더에 넣습니다.
4. 서버를 다시 실행합니다. /reload는 사용하지 마세요.
5. 게임에서 /한글명령어를 입력해 사용 예를 확인합니다.

주요 명령어
//도끼
//첫점
//둘째점
//채우기 돌
//채우기 50%돌,50%흙
//바꾸기 흙 잔디블록
//복사
//붙여넣기
//되돌리기
/영역 생성 마을
/영역 정보 마을
/영역 설정 마을 피브이피 거부
/영역 구성원추가 마을 플레이어이름

알아둘 점
- 기존 영어 명령어도 그대로 사용할 수 있습니다.
- 등록되지 않은 블록, 플래그, 옵션은 영문 이름으로 입력하세요.
- 이 플러그인은 명령을 실행하기 직전에 한글 별칭을 영문 명령으로 변환합니다.
- config.yml의 변환-명령어-표시를 true로 바꾸면 변환된 영문 명령을 볼 수 있습니다.
- 실제 Paper 26.3 서버 구동은 사용자 서버에서 확인해야 합니다. 문제가 생기면 콘솔 오류 전체를 확인하세요.

제거 방법
서버를 종료한 다음 plugins 폴더에서 KoreanCommands-1.0.0.jar를 빼고 다시 실행합니다.
