WorldEdit 7.4.6 / WorldGuard 7.0.21 한국어 수정본

적용 방법
1. 서버 콘솔에서 stop을 입력하고 완전히 종료합니다.
2. 서버 폴더 전체를 백업합니다.
3. plugins 폴더의 기존 worldedit-bukkit-7.4.6.jar와 worldguard-bukkit-7.0.21.jar를 서버 폴더 밖으로 옮깁니다.
4. 이 묶음의 -ko.jar 파일 두 개를 plugins 폴더에 넣습니다.
   같은 플러그인의 원본과 수정본을 동시에 넣지 마세요.
5. 서버를 다시 실행합니다. /reload는 사용하지 마세요.
6. 콘솔의 plugins로 두 플러그인이 정상 활성화되었는지 확인합니다.
7. 게임에서 //wand, /rg help, /rg info를 실행해 한국어 메시지를 확인합니다.

번역 범위와 제한
- WorldEdit: 기본 언어 파일 467개 항목에 한국어 번역 적용(내장 한국어 356개 + 추가 111개).
  명령어 도움말·인수 설명 등도 수정했습니다. 기본 언어와 ko 언어에 적용했습니다.
  기존 사용자 언어 설정이나 다른 언어 번역 파일에 따라 표시가 달라질 수 있습니다.
- WorldGuard: 영역 생성/보호, 플래그, 명령어 도움말, 권한 오류, 각종 알림 및 운영 로그를 번역했습니다.
- 명령어 이름, 플래그 이름, 권한 노드, 설정 키, 파일 이름, 블록 ID 등은 정상 동작을 위해 유지했습니다.
- 모든 텍스트의 100% 번역본은 아닙니다. 일부 WorldEdit 내부 오류와 외부 라이브러리 로그 등은 영어가 남습니다.
- 기존 config.yml, regions.yml 등에 저장된 사용자 지정 영문 메시지는 자동으로 바꾸지 않습니다.
  기존 deny-message, greeting, farewell 등의 메시지는 별도로 변경해야 합니다.
- 공식 배포판이 아닌 수정본입니다. 플러그인을 업데이트하면 번역이 사라질 수 있습니다.

검증
- ZIP 무결성 검사 통과.
- WorldEdit 전체 3,856개, WorldGuard 전체 673개 클래스의 ASM 구조 검사 통과.
- 번역한 문자열의 동적 치환자 및 기본 언어 파일의 숫자 치환자 보존 검사 통과.
- 플러그인 정보, 명령어 식별자, 설정 키 및 번역 대상 밖 파일 유지 검사 통과.
- 실제 Paper 서버 부팅, 명령어 실행, 보호 기능은 이 환경에서 테스트하지 않았습니다.
  서버에 적용한 뒤 콘솔 오류와 기능을 확인해 주세요.

원복
서버를 종료하고 -ko.jar 두 개를 폴더 밖으로 옮긴 뒤, 백업한 원본 JAR 두 개를 복원하고 다시 실행합니다.
