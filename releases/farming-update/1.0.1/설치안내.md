# 도시 농장 Windows 1.0.1

대상: 기존 생활타이쿤 2.0.1/2.0.2 + 도감 1.0.x/1.1.0 + Vault, Paper 26.3 build 238. 서버 전체 RAM 16GB 기준 기존 Windows 백업 관리자·메모리 설정을 유지합니다. 새 화폐·채팅 변환·추가 NPC 플러그인은 없습니다.

## 시작하는 방법

1. 접속 시 **농장 통합 리소스팩 허용**. 거절해도 추방하지 않습니다. 쉬프트+F → 커스텀 농사 → 농장 리소스팩 받기로 재요청합니다.
2. 기존 **농산물 또는 잡화 NPC 우클릭 → 농장 상점 · 씨앗/수확물**. 씨앗을 구매합니다. 좌클릭 1개, 쉬프트 클릭 16개, 우클릭 64개이며 전액·가방 공간을 먼저 확인합니다.
3. 씨앗을 들고 **물에 젖은 경작지 우클릭**. 위쪽 2칸을 비우고 밝기 9 이상을 유지하세요. 물은 경작지에서 가로 4칸 이내, 밤에는 횃불을 둡니다.
4. 성장한 작물을 **우클릭 수확**. 쉬프트+우클릭은 씨앗 1개로 회수하는 확인창입니다. 회수에는 수확물·직업 보상이 없습니다.
5. 쉬프트+F → 커스텀 농사 → 농장 요리에서 제작합니다. **요리 NPC → 농장 요리 · 5종**에서 판매합니다. 도감 등록도 같은 메뉴에서 열 수 있습니다. `/농사`는 보조 안내이며 시작에 필요하지 않습니다.

| 작물 | 첫 수확 시간 | 수확량 | 씨앗 가격 | 매입 가격 | 다음 수확 |
|---|---:|---:|---:|---:|---|
| 딸기 | 8분 | 2~4개 | 40원 | 8원/개 | 25%부터 재성장 |
| 토마토 | 10분 | 2~4개 | 35원 | 7원/개 | 25%부터 재성장 |
| 옥수수 | 15분 | 2~4개 | 30원 | 10원/개 | 제거 후 씨앗 1개 반환 |
| 쌀 | 10분 | 3~5개 | 20원 | 5원/개 | 제거 후 씨앗 1개 반환 |
| 오이 | 9분 | 2~4개 | 30원 | 6원/개 | 25%부터 재성장 |

시간은 물·빛·빈 공간을 만족하고 청크가 로드된 시간만 10초씩 누적합니다. 서버 종료·청크 언로드 중에는 성장하지 않습니다. 성장 단계는 0%, 25%, 60%, 100%입니다. 개인 최대 32그루, 서버 전체 256그루. 농부는 수확 1회에 경험치 2, 기존 적립 보상 설정을 사용합니다(기본 2원). 기존 하루 XP 250·직업 보상 한도를 공유합니다. 적립금은 기존 직업 메뉴에서 수령합니다.

| 요리 | 농부 레벨 | 재료(모두 소비) | NPC 매입 |
|---|---:|---|---:|
| 수제 딸기잼 | 2 | 딸기 3, 설탕 2, 유리병 1 | 40원 |
| 토마토 파스타 | 2 | 토마토 3, 밀 2, 달걀 1, 그릇 1 | 45원 |
| 옥수수 크림수프 | 3 | 옥수수 2, 우유 양동이 1, 그릇 1 | 42원 |
| 도시락 밥 | 1 | 쌀 3, 당근 1, 그릇 1 | 25원 |
| 오이 토마토 샐러드 | 1 | 오이 2, 토마토 1, 그릇 1 | 25원 |

크림수프 제작 시 빈 양동이를 반환합니다. 먹으면 포만감을 주고 용기를 반환합니다. 수확물·요리는 개인/품목별 하루 64개 매입, 한국 시간 자정 초기화이며 재시작해도 유지됩니다. 씨앗은 되팔 수 없습니다. 정품 수확물만 거래·요리·도감에 사용됩니다. 이름이나 데이터를 변경한 물건은 정품으로 취급하지 않습니다.

## 도감 보너스

딸기·토마토·옥수수·쌀·오이 각각 확인 후 정품 1개를 소비해 UUID별 영구 등록합니다. 각 항목 최대 체력 +0.02HP, 다섯 종류 완성 업적 이동 속도 +0.1%입니다. 기존 80종/12업적과 보상은 유지하며 전체 도감은 85종/13업적입니다. 기존 도감 상한(속도 3%, 채굴 6%, 체력 2HP 등)을 그대로 적용합니다. 얻거나 켜도 즉시 체력을 회복시키지 않습니다.

## Windows 설치

1. ZIP을 **실제 서버 폴더 바깥**에 압축 해제합니다. 월드와 `plugins`를 새 폴더로 교체하지 마세요.
2. `Install-Farming.cmd`를 실행하고 `server.properties`가 있는 기존 서버 폴더를 지정합니다. 설치기가 도구/JAR SHA-256을 검사하고 **기존 ServerStop.cmd로 서버와 백업 관리자를 정상 종료**합니다. 종료 파일이 없거나 종료에 실패하면 중단합니다.
3. 서버 잠금·설치 대상 버전·중복 JAR를 검사한 후 **전체 서버 ZIP 백업과 파일별 SHA-256 검증**을 완료해야 JAR를 교체합니다. 백업 위치는 `서버폴더/tycoon-server-backups/전체서버-날짜.zip`, 교체 전 JAR도 같은 위치에 보존합니다.
4. 기존 `ServerStart.cmd`로 시작합니다. 경제 2.0.2·농사 1.0.1·도감 1.1.0이 모두 활성화됐는지 확인합니다. `/reload`로 적용하지 않습니다.
5. 일반 계정으로 NPC 씨앗 구매, 경작지 심기, 수확, 요리, 도감을 확인합니다. 기존 팩을 별도로 중복 적용할 필요는 없습니다.

교체 파일: `KoreanEconomy-2.0.1.jar` → `KoreanEconomy-2.0.2.jar`, `KoreanCodex-1.0.x.jar` → `KoreanCodex-1.1.0.jar`, 신규 `KoreanFarming-1.0.1.jar`. 이전 농사 1.0.0이 있으면 함께 교체합니다. 파일명이 달라도 `plugin.yml`의 플러그인 이름으로 찾아 옮깁니다. 농사 저장소는 기존 경제 SQLite DB에 테이블을 추가하며 잔액·적립금·임무·집·땅·NPC·기존 도감 기록을 초기화하지 않습니다. EssentialsX 본체/Spawn·Vault·GP·Prism·WE/WG·기존 Windows 백업 관리자는 교체하지 않습니다.

첫 실행 때만 `plugins/KoreanFarming/config.yml`을 생성합니다. 기존 농사 설정이 있으면 유지하므로 주소·SHA1을 확인하세요. 기본 팩 SHA1: `aed45dd0f7848a43ec674dcb072772260def7882`. 리소스팩 거절 시 기본 아이콘으로 구입할 수 있지만 심기/수확은 팩 적용 확인 후 가능합니다. 수동 설치는 ZIP의 `resourcepacks/CityEconomy-Farming-26.3-1.1.0.zip`을 게임 리소스팩 폴더에 넣고 활성화한 후 메뉴의 **수동 적용 확인**을 누릅니다. 이 버튼은 사용자 확인이며 클라이언트 파일을 서버가 검사하는 기능은 아닙니다. 한 번 거절하면 Minecraft가 서버별로 거절을 기억할 수 있습니다. 팩 받기 버튼을 눌러도 창이 안 뜨면 접속을 끊고 멀티플레이 → 서버 선택 → 편집 → 서버 리소스 팩을 **물어보기** 또는 **사용**으로 바꾼 뒤 재접속하세요. Complete 팩은 도시 건축 텍스처 8개도 교체하는 선택 사항입니다.

## 백업·복원과 확인 대기 거래

기존 Windows 백업 관리자의 `/백업 지금`·주기 설정을 유지합니다. 관리자는 서버를 저장/정상 종료한 뒤 월드와 플러그인 데이터를 냉백업하고 재시작하며, 압축은 별도 작업으로 진행합니다. `/서버백업`은 경제 DB·플러그인 설정 스냅샷이며 월드와 Vault 잔액 전체 백업은 아닙니다. 두 종류를 구분하세요. 농장 DB는 경제 DB에 포함됩니다. 단순 실행 중 월드 복사를 완전한 백업으로 취급하지 않습니다.

전체 설치 백업 검증: `java -jar FarmInstaller.jar 검증 "전체서버-날짜.zip"`.

복원: 먼저 `ServerStop.cmd`로 정상 종료합니다. ZIP을 서버 밖에 둔 뒤 `java -jar FarmInstaller.jar 복원 "서버폴더" "전체서버-날짜.zip" --서버종료확인`을 실행합니다. 도구는 백업을 검증하고 복원 직전 서버도 따로 백업한 다음 전체 트리를 복원하므로 백업 이후 새 파일이 끼어 남지 않습니다. 기존 관리자 주기 백업은 해당 관리자의 복원 도구를 사용하세요. 서로 다른 백업 형식의 복원 도구를 혼용하지 마세요.

운영자 `/농사관리 목록`, `/농사관리 거래`, `/농사관리 번호 <번호>`로 확인합니다. 결과가 불확실한 거래는 잠금/확인 대기로 남고 자동 재지급하지 않습니다. 실제 플레이어 아이템과 잔액을 확인한 뒤 `/농사관리 완료 <번호> 확인` 또는 `/농사관리 취소 <번호> 확인`으로 기록을 정리합니다. 완료/취소는 아이템·돈을 다시 지급하거나 회수하지 않으므로 실제 결과를 확인해야 합니다. 최종 저장 오류로 경제 엔진이 일시 정지되면 원인을 해결하고 서버를 정상 재시작합니다.

검증 범위는 [검증결과.md](검증결과.md)를 보세요. 테스트 도구 FarmProbe/CodexProbe/ViaVersion/ViaBackwards는 배포/운영 서버에 포함하지 않습니다.
