# 검증 결과 — 2026-11-11 Windows / Paper 26.3 build238

## 실제 운영 폴더 적용

사용자가 지정한 Windows 서버 폴더에 접근하여 적용했습니다. 서버와 기존 백업 관리자를 ServerStop.cmd로 정상 종료했습니다. 설치 전 전체 백업을 만들고 **638개 파일을 별도 폴더에 복원한 후 원본 manifest의 모든 SHA-256과 대조**했습니다.

- 기존 JAR **16개 바이트 동일**, 공식 추가 5개와 KoreanServerBridge 1개를 넣어 **22종**입니다. 같은 이름의 중복 JAR가 없습니다.
- 설치 직전 경제/농사 DB 12개 테이블, 도감 DB 5개 테이블의 파일 바이트가 원본과 같았습니다. 시작·백업·재시작 후에도 **17개 테이블의 기록 수가 유지**되고 SQLite integrity_check가 정상입니다. 개인 기록·UUID·DB·월드·인벤토리·비밀번호는 GitHub에 올리지 않았습니다.
- 기존 파일 중 의도적으로 바꾼 것은 GriefPrevention의 메시지 파일입니다. 기존 한글 45문구를 유지하고 영문 187문구를 번역했습니다. 원본 전체 백업과 별도 메시지 백업을 남겼습니다. 보호·친구 권한·설정 키·치환값은 바꾸지 않았습니다.
- EssentialsX/Spawn **2.22.1-dev+28-f8724e2** 유지. WorldGuard·GriefPrevention·Prism·QuickShop·통합팩·기존 자체 JAR를 유지했습니다.
- 실제 로그에서 신규 6개 활성화, Vault의 기존 Essentials 경제 연결, PAPI koreanlife 확장 등록, TAB 활성화를 확인했습니다. 선택 조합의 새 시작 로그에서 ERROR/예외/미지원 서버 오류가 없었습니다.
- **마을 안내판 1개**가 저장되고 재시작 후에도 1개입니다. 기존 NPC를 생성·삭제하지 않았습니다.
- 기존 오버월드 리전 범위를 확인하고 경계 지름 **4096**, 콘솔 좌표 중심 **0,0**을 설정했습니다. Minecraft의 정수 좌표 해석에 따른 저장 중심은 **0.5,0.5**입니다. 경계 전체 생성과 구분하여 중심 반경 **512 / square / 4225청크** 생성이 약 **20초**에 완료됐습니다. 기존 경계는 기본값 59999968이었습니다.
- 기존 Windows 관리자의 정상 종료 → 스냅샷 → 별도 압축 작업 → 재시작을 실제 실행했습니다. 새 백업의 SHA-256·ZIP 무결성·필수 파일과 **LuckPerms H2 데이터 및 22개 JAR** 포함을 검사했습니다.
- 실제 재시작 후 저장된 오버월드 world_border.dat에서 4096과 중심값을 읽었습니다. 인증 online-mode=true와 리소스팩 선택 사항 require-resource-pack=false를 유지합니다. 운영 프로세스만 남겼으며 복제 서버와 시험 게임은 종료했습니다.

집계 증거: [설치 직전 복원](deployment-cold-audit.json), [운영 적용·재시작](production-verification.json). 비공개 백업·원본·복원 사본은 로컬에만 있습니다.

## 실제 Paper 서버에서 자동 클라이언트 검사

인터넷 공개 운영 서버에 시험 데이터를 넣지 않았습니다. localhost의 오프라인 **복제 서버**는 실제 Paper 26.3 build238과 운영 조합을 사용했습니다. 자동 클라이언트는 Mineflayer 26.1이므로 **테스트 전용 ViaVersion/ViaBackwards 5.12.2**로 연결했습니다. 이 두 플러그인과 계측 JAR는 운영·설치 ZIP에 없습니다.

동일한 15개 검사를 정상 재시작 전후 각각 통과했습니다. 가짜 API만으로 실행한 검사가 아닙니다.

1. 통합팩 요청이 실제 네트워크에서 1회이며 거절 후에도 접속·기본 메뉴 유지.
2. 시험용 실제 Vault 잔액 4321.25원, 농부 저장 레벨3, 실제 수확 적립금2원, 도감1/85·업적0/13·접속 수를 PAPI와 대조.
3. 실제 TAB 사이드바 패킷에 한국어 제목/실제 잔액 표시.
4. 기존 메뉴 47번 칸과 실제 클릭 위치 일치, 새 화면에 같은 값 표시.
5. 우클릭으로 UI 아이템을 가져오거나 실행하지 못함.
6. 기존 도감·마을 수첩 복귀 연결.
7. 야생 검증 대기 안내 후 돈 차감 없음.
8. 일반 이용자의 한국어 운영 명령 3개 거부.
9. 실제 Bukkit 권한에서 돈 생성·기록 복구·땅 우회·등급 편집 불가.
10. 한국어 정보판 켜기·끄기 실제 TAB 동작.
11. 실제 DH 권한 거부 문구 한국어 표시.
12. 단골 상속·실제 등급 표시, 운영 권한 없음.
13. 명시적으로 부여한 운영자 등급은 제한된 운영 권한만 있고 OP·돈 생성·등급 편집 권한 없음. 별칭으로 승급 우회 불가.
14. 등급 회수 후 재접속 없이 즉시 권한·표시 변경.
15. 안내판 반복 연결·재시작 후 1개, 잔액·기록 불변.

추가로 빈 가방의 새 시험 계정에서 **GriefPrevention 실제 접속 안내가 한국어로 바뀐 것**을 확인했습니다. 187개 문구의 모든 상황을 게임에서 실행한 것은 아닙니다. 원래 메시지 키·치환값 전체 보존은 자동 검사했습니다.

증거: runtime-before.json, runtime-after.json, language-runtime.json. 숫자·아이템·등급 변경은 복제 서버의 합성 시험 계정에만 적용했습니다.

## 실제 Minecraft 26.3 게임 화면

별도 시험 클라이언트로 복제 서버에 일반 이용자로 접속했습니다. 실제 한국어 사이드바, 쉬프트+F → 새 마을 정보 → 기존 도감 화면, 기존 NPC 우클릭 상점을 확인했습니다. 기존 전용 아이콘·작물/도감 연결과 실제 개인 값(시험 계정의 968원·적립금2원·도감2/85)이 표시됐습니다. 새 마을 홀로그램의 개인 값도 실제 화면에서 확인했습니다.

시험 클라이언트는 이 PC에서 이전에 확인된 LWJGL 네이티브 충돌을 피하기 위해 **-Xint**로 실행했습니다. 일반 JIT 모드의 클라이언트 안정성이 해결됐다고 주장하지 않습니다. 사용자의 기존 클라이언트 설치·계정·프로필을 바꾸지 않았습니다.

안내판 확인을 위한 운영자 고정 좌표 이동 중, 복제 월드의 구조물 안에 시험 계정을 이동시켜 질식 사망이 발생했습니다. 리스폰 후 잔액·도감 표시 유지는 확인했고 가방을 자동 재지급하지 않았습니다. 이 고정 이동을 실제 운영 서버에 적용하지 않았습니다. 안내판의 새 기본 배치는 최고 지면 높이를 고려하도록 보완했습니다. 운영 서버에서 인증된 실제 계정으로 같은 플레이를 수행하지는 못했습니다.

## 빌드·단위·설치기 검사

- 실제 설치 **Paper API 26.3.build.238-stable**로 Java27 컴파일, target21. 배포 JAR에 Bukkit/API/시험 클래스를 포함하지 않았습니다.
- 표시 스냅샷 불변성·잔액 정밀도·NaN/음수·미확인 값·등급 대체 표시 **13개 계약 검사** 통과.
- Windows PowerShell 설치 사전 검사 **5개** 통과: 정확한 정상 조합, 중복 식별자 거부, 수정된 설정 보존, 다른 빌드 다운그레이드 거부, 손상된 입력 JAR 거부. 합성 폴더 검사이며 게임 검사가 아닙니다.
- 공식 5개 파일을 다운로드 전용 스크립트로 실제 내려받아 이름·버전·SHA-256을 확인했습니다.
- 기존 경제/농사/도감의 기능 소스·JAR는 수정하지 않았습니다. 이전 UI 배포의 모의 141검사·SQLite 121검사를 이번 새 모듈의 실행 검사 수에 합산하지 않습니다. 같은 기존 돈·아이템·보상 엔진을 재사용합니다.

## 남은 항목

**BetterRTP·NPC 야생 이동은 보류**입니다. 무료 3.6.13의 안내는 테스트 버전 1.20까지이며 26.3 지원을 확인하지 못했습니다. 공식 바이너리 다운로드·실행 준비 작업은 자동 승인 검토가 차단했고 세부 이유는 제공되지 않았습니다. 공개 소스 빌드 대안도 오래된 Spigot·보호 API 의존 및 저장소 DNS 문제로 확보하지 못했습니다. 기존 EssentialsX 랜덤 이동도 비동기 완료·비용 청구 순서 때문에 실패 시 차감 검증이 남아 활성화하지 않았습니다. /야생과 버튼은 준비 상태만 안내합니다.

10명 동시 장시간 부하, 경계 전역/네더/엔드 생성, 인증된 운영 계정의 전체 플레이, 모든 고급 운영 문구 완전 한글화, 외부 인벤토리 복구 플러그인과의 정산은 미검증입니다. TAB·DH·PAPI 고급 운영 명령 일부는 영문입니다. 권한을 우회하거나 경고를 숨겨 해결했다고 표현하지 않습니다.
