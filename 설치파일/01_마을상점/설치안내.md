# 마을·개인상점 설치

이 폴더는 기존 생활 경제 서버의 **마을 설립·필지 매매·개인상점** 업데이트입니다. Paper 26.3 build238 / Java 25 이상 / 기존 KoreanEconomy·Vault 환경을 대상으로 합니다.

1. **도시생활-마을상점-한글설치-1.0.0.zip**을 받고 서버 폴더 밖에 압축을 풉니다. ZIP 전체를 함께 사용하세요.
2. **설치하기.cmd**를 실행합니다. `server.properties`가 있는 실제 서버 폴더를 선택하세요.
3. 기존 `ServerStop.cmd`가 있으면 정상 종료를 실행합니다. 없으면 콘솔에서 `stop`으로 종료하고 설치창에 `종료확인`을 입력합니다.
4. 검증된 설치기가 **전체 서버 백업과 해시 검증 후** 필요한 6개 플러그인을 설치합니다. 기존 설정·잔액·집·월드·농장·도감은 유지합니다.
5. 기존 실행기로 서버를 켠 뒤 **쉬프트+F → 마을·땅 거래 / 개인상점**을 사용합니다.

## 설치 파일

| 한글 파일명 | 플러그인 식별자 | 버전 |
| --- | --- | --- |
| 플러그인/생활경제-2.0.3.jar | KoreanEconomy | 2.0.3 |
| 플러그인/마을수첩-2.2.0.jar | KoreanMenu | 2.2.0 |
| 플러그인/도시화면-1.2.0.jar | CityTextures | 1.2.0 |
| 플러그인/마을상점-1.0.0.jar | KoreanCivic | 1.0.0 |
| 플러그인/커스텀농사-1.0.2.jar | KoreanFarming | 1.0.2 |
| 플러그인/아이템도감-1.2.1.jar | KoreanCodex | 1.2.1 |

한글 JAR는 기존 검증 배포와 **내용이 동일**합니다. 설치기는 임시 폴더에서 원래 설치 파일명으로 준비해 검증된 설치 도구에 전달합니다. 실제 서버의 플러그인 식별자·설정 폴더·파일 관리 방식은 유지됩니다. JAR를 수동으로 중복 추가하기보다 이 설치기를 사용하세요.

`리소스팩/도시생활-메뉴팩-1.2.0.zip`은 기본 통합 화면팩, `도시생활-전체팩-1.2.0.zip`은 선택 건축 재질을 포함한 전체팩입니다. 서버가 요청하는 기존 다운로드 주소도 그대로 작동합니다.

`설치목록.json`은 파일 이름과 SHA-256 목록입니다. `파일검증.sha256`으로 묶음의 파일을 확인할 수 있습니다. `검증자료`는 이전 기능 배포의 원본 검사 기록입니다. 파일 정리와 설치 준비 검사 결과는 `정리검증.json`에 구분합니다.

## 적용 상태와 복원

게임 기능의 자동 검사와 설치기 백업·복원 검사는 완료했습니다. 이번 한글 파일 묶음의 **Windows 운영 적용·실제 게임 접속 검증은 수행하지 않았습니다.** 현재 작업은 파일·폴더 정리이며 게임 기능이나 보상을 바꾸지 않습니다.

경제 저장소는 스키마 2를 사용합니다. 버전을 되돌릴 때는 예전 JAR만 덮어쓰지 말고 서버 종료 후 전체 백업을 함께 복원하세요.

```powershell
java -jar 설치도구.jar 복원 "C:\서버폴더" "C:\서버폴더\tycoon-server-backups\전체서버-날짜.zip" --서버종료확인
```

판매대금·미확정 거래 정리는 [거래·복구안내](거래·복구안내.md), 화면 예시는 [메뉴 미리보기](메뉴-미리보기.png)를 참고하세요.
