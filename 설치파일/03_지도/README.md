# 경제 마을 지도

[**자연형 마을 3판 받기**](경제마을-자연형-3판.schem) · [평면도](경제마을-평면도-3판.png) · [전체 모습](경제마을-전체모습-3판.png) · [상세 설치 안내](경제마을-설치안내-3판.txt)

`.schem` 파일을 서버의 `plugins/WorldEdit/schematics`에 넣습니다. 게임에서 붙여 넣을 위치를 확인한 뒤 아래처럼 불러옵니다.

```text
//schem load "경제마을-자연형-3판.schem"
//paste -a
```

기존 건축물이 있는 위치에 붙여 넣기 전에 월드 백업과 위치·높이를 확인하세요. 이 파일은 건축물 스키매틱입니다. 마을 소유권이나 경제 기능은 [마을·개인상점 플러그인](../01_마을상점/README.md)에서 따로 이용합니다.
