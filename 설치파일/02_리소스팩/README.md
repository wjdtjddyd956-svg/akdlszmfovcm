# 리소스팩

| 파일 | 용도 |
| --- | --- |
| [도시생활 메뉴팩 1.2.0](도시생활-메뉴팩-1.2.0.zip) | 메뉴·직업·요리·도감·업적·커스텀 농장 아이콘과 작물 모델 |
| [도시생활 전체팩 1.2.0](도시생활-전체팩-1.2.0.zip) | 메뉴팩 내용 + 선택 건축 재질 |

Minecraft의 **설정 → 리소스 팩 → 팩 폴더 열기**에서 ZIP을 넣고 선택합니다. 서버가 보내는 통합팩 요청을 허용하는 방법도 있습니다. 같은 메뉴팩과 전체팩을 동시에 겹쳐 켤 필요는 없습니다.

팩을 직접 설치한 뒤 `/도시팩 메뉴켜기`로 메뉴의 설치 확인을 할 수 있습니다. 이 명령이 게임에 ZIP을 직접 복사하는 것은 아닙니다.

파일 내용은 기존 `CityEconomy-Interface` 배포와 같습니다. 서버 설정에 저장된 기존 팩 주소는 계속 유지합니다. [최신 기능 설치 ZIP](../01_마을상점/도시생활-마을상점-한글설치-1.0.0.zip)에도 두 팩을 포함했습니다.
