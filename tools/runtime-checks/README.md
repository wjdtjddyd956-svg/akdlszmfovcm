# 실제 Paper 복사본 검사 원본

이 스크립트는 운영 서버용 플러그인이 아닙니다. 월드·아이템·잔액·권한을 바꾸는 **일회성 테스트**입니다. 실제 서버를 종료 상태로 복사한 별도 폴더만 사용하고 외부 접속을 차단하세요. `TYCOON_ISOLATED_TEST_COPY=YES`가 없으면 실행을 거부하며 접속 대상은 `127.0.0.1:25566`, RCON은 `127.0.0.1:25577`로 고정합니다. RCON 암호는 `TYCOON_TEST_RCON_PASSWORD_FILE`이 가리키는 별도 비공개 파일에서 읽습니다. 암호 파일은 커밋하지 마세요.

테스트 클라이언트는 Mineflayer 4.39.0 / minecraft-protocol 1.68.0 / minecraft-data 3.119.0입니다. 서버 복사본에만 ViaVersion/ViaBackwards 5.12.2를 넣어 26.1 프로토콜로 실제 Paper 26.3에 접속했습니다. 잘못된 이동 패킷을 피하기 위해 봇의 물리 이동을 껐고 위치는 테스트 RCON으로 제어합니다. 운영 서버에는 이 어댑터·RCON·테스트 플러그인을 넣지 않았습니다. 순정 26.3 화면 검증은 별도 실행했습니다.

`npm install` 후 순서대로 실행할 수 있지만 **준비된 테스트 월드/데이터가 전제**입니다. 재실행은 동일한 초기 복사본으로 되돌린 뒤 해야 합니다. 날짜는 최초 검사일의 한국 날짜이며 날짜가 바뀌면 기존 일일 상태 검사의 기대값을 갱신해야 합니다.

- `01-features.cjs`: 신규 TycoonPatch UUID, 기본 요리·강화 설정, 평지와 두 테스트 NPC. 11개 그룹.
- 서버를 정상 종료·재시작하고 `02-restart.cjs`: 앞 단계 잔액 1120원·요리 매입량 3·완료 임무·강화 도구 유지. 일반 상인 매입 한도와 구매 검사. 8개 그룹.
- `03-regression.cjs`: 1.2의 PackTestB 광부 기록이 있는 복사본. 실제 작물·광석 파괴, GP·Prism·집·스폰·송금 등 10개 그룹. GP 땅 생성·배치 광석 표시·상자 열기에는 테스트 전용 LifeTest를 사용했습니다. 상자 클릭·블록 파괴·Prism 조회/복구는 실제 서버 이벤트입니다. 이 테스트 보조 JAR는 배포하지 않습니다. 원본은 이전 `life-server/검증.md`의 방법을 따릅니다.
- `04-failures.cjs`: 원본 설정을 백업하고 테스트 복사본에서만 밀빵 매입가 13/한도 4, 2단계 강화 비용 10/확률 0으로 바꿔 `/경제설정 새로고침`. 동시 클릭·매입 초과·강화 실패 3개 그룹.
- `05-stale.cjs`: 손 도구 변경·NPC 거리 이탈 후 거래 거부 2개 그룹. 메뉴가 열린 중 서버가 바꾼 아이템의 클라이언트 표시 동기화에는 어댑터 제약이 있어 잔액과 서버의 거부 응답으로 판정합니다.
- `06-backup-notice.cjs`: 현재 운영 서버와 같은 최신 Windows 관리자 코드, 테스트 옵션 `warningSeconds:2`에서 백업 예고 한국어 수신 1개 그룹. 관리자의 정상 종료·압축·재시작·성공 기록은 파일/로그로 별도 확인했습니다.

개발 과정에서 테스트의 메뉴 슬롯·권한 거부 문구·오프라인 송금 대상·봇 인벤토리 동기화 가정이 맞지 않아 중단된 실행이 있었습니다. 기대값·접속 준비를 보정한 뒤 성공한 항목만 최신 보고서에 포함했습니다. 과거 테스트 복사본의 구형 압축 작업은 `Get-FileHash`를 찾지 못해 실패했으며, 실제 운영 서버의 기존 수정된 관리자 코드와 같게 맞춘 뒤 재검사에서 성공했습니다. 운영 서버에는 그 구형 코드가 설치되지 않았습니다.

실제 낚시를 시작해서 랜덤 물고기를 잡는 전 과정, 10명 동시 활동, 전원 차단 실험을 했다는 뜻은 아닙니다. 중단 결과가 불확실한 경제 거래의 장애 주입은 `korean-economy/src/test/.../ActionTest.java`의 테스트 대역과 실제 SQLite에서 검사합니다.
