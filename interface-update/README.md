# 도시 생활 수첩 UI 업데이트 1.2.1

[Windows 설치 ZIP](../releases/ui-update/1.2.1/도시생활-Windows-메뉴통합-1.2.1.zip) · [설치 안내](../releases/ui-update/1.2.1/설치안내.md) · [Windows·실제 게임·모의 검사 구분](../releases/ui-update/1.2.1/검증결과.md)

쉬프트+F 메뉴·아이템 도감·업적·능력치 화면의 가독성과 표시 정확도를 개선합니다. Paper 26.3용이며 별도 클라이언트 모드는 필요하지 않습니다.

- **KoreanMenu 2.1.0**: 경제 / 수집·농장 / 이동·생활 / 성장·직업을 색상과 위치로 구분. 도감·업적·농장 버튼을 메뉴에서 직접 관리하고 등록 현황을 표시합니다. 활성화되지 않은 기능은 ‘준비 중’으로 안내합니다. NPC 상점 버튼은 마을 NPC 거래 안내를 제공합니다.
- **KoreanCodex 1.2.1**: 분야별 진행률, 실제 등록 가능한 보유 수량, 전체·등록 가능·미보유·등록 완료 필터, 등록 완료 강조, 업적의 남은 목표 수, 현재 적용 중인 효과와 상한을 표시합니다. 미결 거래·모드 제한은 ‘등록 대기’로 구분합니다.
- 등록 확인창은 **소비 전 실제 증가량**을 계산합니다. 이번 등록으로 함께 달성할 업적도 표시하고, 이미 상한이면 더 증가한다고 안내하지 않습니다. 아이템 1개 소비 확인은 유지합니다.
- **CityTextures 1.1.1**: 도감·업적·분야·능력치·등록 상태용 아이콘 24종을 추가합니다. 버튼의 표시 이름 대신 고정된 기능 키로 아이콘을 연결합니다. 플레이어 가방·일반 상자·도구 강화의 실제 도구는 장식하지 않습니다.
- **KoreanFarming 1.0.2**: 통합팩 성공 시 농작물도 준비됩니다. 같은 접속에 도시팩과 농장팩을 각각 요청하지 않습니다. 별도로 적용한 농장팩은 메뉴팩 다운로드 실패 시에도 준비 상태를 유지합니다.
- **KoreanEconomy 2.0.2**: 기존 농장 연동 버전을 그대로 포함합니다. 기존 경제·직업·땅·집·도감·플레이어 데이터를 이어받습니다.

## 설치

1. ZIP을 서버 밖에 풉니다. Windows 설치기는 파일 SHA-256 검사 후 기존 `ServerStop.cmd`로 서버와 자동 백업 관리자를 정상 종료합니다. 이 종료 파일이 없으면 중단합니다.
2. 설치 ZIP을 **서버 폴더 밖**에 풀고 `Install-Interface.cmd`를 실행합니다. `server.properties`가 있는 서버 폴더를 지정합니다.
3. 설치기는 파일·버전·잠금을 검사하고 전체 서버를 백업·검증한 뒤 해당 플러그인 이름의 기존 JAR만 바꿉니다. 기존 데이터 폴더와 타사 플러그인은 유지합니다. 생활타이쿤 2.0.1/2.0.2에서 업그레이드할 수 있습니다.
4. 기존 `ServerStart.cmd`로 시작합니다. 접속할 때 **통합 리소스팩을 허용**한 뒤 쉬프트+F를 누릅니다.
5. 직접 설치한다면 `resourcepacks/CityEconomy-Interface-26.3-1.2.0.zip`을 Minecraft 리소스팩 폴더에 넣고 선택합니다. 쉬프트+F → 메뉴 리소스팩 → **직접 설치 확인**을 누릅니다. 서버는 클라이언트의 수동 설치 파일을 자동 검사할 수 없으므로 실제 선택 후 눌러야 합니다.

수동으로 JAR를 복사할 때에는 먼저 전체 백업을 만들고 `plugins/`의 새 JAR 5개를 넣습니다. 같은 플러그인의 이전 JAR는 서버 밖으로 옮겨 한 개씩만 남기며 데이터 폴더는 지우지 않습니다. `/reload` 대신 정상 재시작하세요. 더 새로운 미확인 플러그인 버전은 설치기가 덮어쓰지 않습니다.

팩을 거절하거나 다운로드가 실패해도 접속과 기본 메뉴·도감은 유지됩니다. 새 메뉴 전용 모델은 성공 확인 또는 직접 설치 확인 후 표시합니다. 기존 도시팩만 켠 이용자에게는 새 아이콘을 적용했다고 가정하지 않습니다.

## 사용

- 쉬프트+F → **아이템 도감** → 분야 선택 → 등록 가능 필터 → 아이템 선택 → 실제 보상 확인 → 1개 소비 확인.
- **등록 완료** 필터에서는 이미 등록한 항목을 볼 수 있고 다시 클릭해도 소비하지 않습니다.
- **업적**은 달성한 수, 목표 진행률, 남은 등록 수와 추가 보상을 표시합니다.
- **내 수집 효과**는 현재 적용량·수집한 보너스·전체 상한·개인 켜짐 상태를 구분합니다. 창조·관전자 모드에서는 미적용으로 표시합니다.
- 도감 화면의 **마을 수첩** 버튼으로 쉬프트+F 메뉴로 돌아갑니다.
- 쉬프트+F → **메뉴 리소스팩**에서 아이콘 미리보기·다운로드·직접 설치 확인을 이용합니다. 기존 `/도시팩` 명령도 유지합니다.

기존 85종·13업적의 ID·희귀도·등록 보상·소비 규칙·능력치 상한·DB 스키마 2는 바꾸지 않습니다. 보유 수량은 장비·보조 손을 제외한 가방 36칸의 정품만 셉니다. 커스텀 수확물은 해당 농사 플러그인이 확인한 아이템만 인정합니다. 색상 외에도 ‘등록 가능 / 미보유 / 등록 완료 / 등록 대기’ 문구를 함께 표시합니다.

## 리소스팩 설정

새 설정은 **`plugins/CityTextures/ui.yml`**입니다. 기존 `config.yml`과 수동 도시팩 설정은 보존합니다.

- `사용`: 새 통합팩 사용 여부.
- `접속시-요청`: 통합팩 자동 다운로드 요청. 기본 true. false로 바꾸면 메뉴에서 직접 요청합니다.
- `팩-주소` / `체크섬-SHA1`: 공개 HTTPS ZIP 주소와 실제 ZIP의 SHA1. 기본은 이 저장소의 새 통합팩입니다.
- `직접설치-확인`: 직접 설치를 확인한 UUID 목록. 이전 도시팩의 수동 확인 목록과 구분합니다.

기본 통합팩은 기존 도시 아이콘 32개 + 농장 아이콘 15개 + 성장 모델 20개 + 새 UI 아이콘 24개를 포함합니다. Minecraft의 기본 건축 텍스처를 전역 변경하지 않습니다. `Complete` 팩에는 도시 건축 재질 8개를 추가합니다. 서버가 Complete를 요청하게 바꾸려면 **주소와 Complete의 SHA1을 함께** 바꾸세요. 값은 `resourcepack-validation.json`에 있습니다.

## 저장·검증·복원

경제·농장은 `KoreanEconomy/생활경제.db`, 도감은 `KoreanCodex/도감.db`를 유지합니다. 아이콘·필터·진행률 확인만으로 돈·아이템을 바꾸지 않습니다. 실제 등록·거래에는 기존 저장 저널·확인 대기·권한·중복 방지를 사용합니다. 설치 전 전체 서버 백업으로 월드·플레이어·플러그인 자료를 같은 시점으로 복원하세요.

실제 Paper API와 Java 25로 컴파일하고 MockBukkit 26.3·파일 SQLite로 기존 경제/도감/농장 및 UI 연결을 검사합니다. 검사 수와 한계는 `validation.json`과 `installer-validation.json`에 기록합니다. 생산 JAR의 SQLite 드라이버·Windows DLL·클래스 버전과 ZIP 체크섬도 확인합니다.

`메뉴-미리보기.html/png`는 **실제 플러그인을 MockBukkit에서 실행해 추출한 슬롯·이름·설명**으로 만든 구성 미리보기입니다. 실제 Minecraft 화면 캡처는 아닙니다. 기본 Minecraft 아이템은 이름 타일로 표시하며, 새 전용 아이콘은 배포팩의 실제 PNG를 사용합니다. 게임의 GUI 배율과 글꼴에 따라 표시가 달라질 수 있습니다.

1.2.1은 2026-11-11 전체 백업·636파일 복원 검증 후 실제 Windows에 적용했습니다. 실제 Paper 복제본과 Minecraft26.3 클라이언트(-Xint 진단 모드)에서도 확인했습니다. 일반 JVM의 팩 전환과 10명 부하는 별도 확인이 남았습니다. 이전 2.0.1/도감 1.0.1의 Windows 검증 이력과 구분합니다. 빌드: `python3 interface-update/build.py`. 이전 농장 1.0.0 재현은 커밋 ee8edb8, 도시팩 1.0 재현은 커밋 99e3599의 별도 체크아웃을 사용합니다.

Windows 빌드·검사·패키징: `python interface-update/windows.py build|test|package --server "서버폴더" --jdk "JDK폴더"` (빌드/운영 JDK27, MockBukkit 검사 JDK25). 1.2.0 배포본 재현은 커밋 61c7e2f의 별도 체크아웃을 사용하세요.
